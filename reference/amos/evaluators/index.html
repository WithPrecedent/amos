    Techniques that evaluate a fitted model with tables.

    These are techniques of the "critic" stage. Each one adds a table to the dataset's tables (under the technique's name). Most evaluate the model on the test rows (or on every row, if the data has not been split). factor_analysis and pca instead describe the features that the model learned from, so they work in any stage. Pass visualize = True (or set "visualize_critics" in the "general" section of the settings) and each one also draws its table as a figure in the dataset's figures, under its name (see base.Visualizer).

    Contents

    Evaluator: base class for techniques that evaluate a model with a table. BiasVariance: the model's expected error, as its bias and variance. ClassificationReport: precision, recall, and f1 for each class. Confusion: how many rows of each class were predicted to be each class. Conformal: prediction intervals (or sets) with a known rate of coverage. ExplainWeights: eli5's explanation of the weights of the features. FactorAnalysis: the hidden factors that explain the correlations of the features. Fairness: how the model does for each group, and the gaps between them. FeatureImportance: the importance that the model gives each feature. PCA: how much of the variance of the features each principal component has. PermutationImportance: how much the score drops when each feature is shuffled. RegressionTable: the coefficients (or average marginal effects) of every model side by side, with their standard errors and cross-validated metrics, ready to publish like a scorecard. Scorecard: every standard metric for every branch of an analysis, ready to publish as csv, Markdown, LaTeX, HTML, Word, or an image. ShapImportance: the mean absolute SHAP value of each feature.

    BiasVariance(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Evaluator

    The model's expected error on the test rows, as its bias and variance.

    mlxtend's bias-variance decomposition: copies of the model are fitted to rounds bootstrap samples of the training rows, and each predicts the test rows. The expected loss is their mean loss: the share of rows misclassified (0-1 loss), for a classifier, or the mean squared error. The bias is the loss of their main prediction (the most common class, or the mean), and the variance is how far the copies' predictions are from it. A model with a large bias underfits; one with a large variance overfits. The table has one row, with the "loss", "expected_loss", "bias", and "variance".

    Wraps

    mlxtend.evaluate.bias_variance_decomp from mlxtend.

    def evaluate(
    self,
    item: base.Dataset,
    rounds: int = 100,
    **kwargs: Any) -> pd.DataFrame:
    """Returns the expected loss of the model, and its bias and variance.

    Args:
        item: the dataset with a fitted scikit-learn model and test rows.
        rounds: number of bootstrap samples (and copies of the model).
            Defaults to 100.
        **kwargs: not used.

    Raises:
        TypeError: if the model is not a scikit-learn estimator.
        ValueError: if the data is not split.
        IncompatibleTechniqueError: if the model is not from scikit-learn.

    Returns:
        One row, with the loss and its parts.

    """
    evaluate = utilities.import_tool('mlxtend.evaluate')
    sklearn = importlib.import_module('sklearn.base')
    if not item.is_split:
        message = 'bias_variance needs test rows: split the data first'
        raise ValueError(message)
    model = _model(item)
    names = list(
        utilities.feature_names(model, item.data.columns) or item.features)
    y_train, y_test = item.y_train, item.y_test
    if isinstance(model, models.LabelCoded):
        model = model.estimator
    if item.task == 'classify':
        # mlxtend counts the predictions of each class by its number.
        positions = {c: i for i, c in enumerate(item.classes)}
        y_train, y_test = y_train.map(positions), y_test.map(positions)
    if not isinstance(model, sklearn.BaseEstimator):
        message = (
            f'bias_variance needs a scikit-learn model, not a '
            f'{type(model).__name__}')
        raise base.IncompatibleTechniqueError(message)
    loss = '0-1_loss' if item.task == 'classify' else 'mse'
    expected, bias, variance = evaluate.bias_variance_decomp(
        sklearn.clone(model),
        item.x_train[names].to_numpy(),
        y_train.to_numpy(),
        item.x_test[names].to_numpy(),
        y_test.to_numpy(),
        loss = loss,
        num_rounds = rounds,
        random_seed = item.seed)
    return pd.DataFrame({
        'loss': [loss],
        'expected_loss': [float(expected)],
        'bias': [float(bias)],
        'variance': [float(variance)]})

    Conformal(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Evaluator

    Prediction intervals (or sets) with a known rate of coverage.

    Conformal prediction turns any model's predictions into intervals (for regression) or sets of classes (for classification) that contain the true value for at least a chosen share of rows ("confidence", 90% by default), without assumptions about the data's distribution. It wraps MAPIE's cross-conformal methods, which refit copies of the model on folds of the training rows ("cv", 5 by default). The table has a row for each test row. The share of rows covered ("coverage") and the mean width of the intervals ("interval_width") or size of the sets ("set_size") are stored in the dataset's metrics.

    Wraps
    • mapie.classification.CrossConformalClassifier from MAPIE, to classify.
    • mapie.regression.CrossConformalRegressor from MAPIE, to regress.

    def apply(self, item: base.Dataset, **kwargs: Any) -> base.Dataset:
    """Adds the table and stores the coverage and width (or set size).

    Args:
        item: the dataset with a fitted model.
        **kwargs: parameters for `evaluate`, and `visualize` (see
            `Evaluator.apply`).

    Returns:
        The dataset, with the table in `tables` and the coverage in
            `metrics`.

    """
    super().apply(item, **kwargs)
    table = item.tables[self.name]
    item.metrics['coverage'] = float(table['covered'].mean())
    if 'lower' in table.columns:
        item.metrics['interval_width'] = float(
            (table['upper'] - table['lower']).mean())
    else:
        item.metrics['set_size'] = float(table['size'].mean())
    return item

    def evaluate(
    self,
    item: base.Dataset,
    confidence: float = 0.9,
    cv: int = 5,
    **kwargs: Any) -> pd.DataFrame:
    """Returns the interval (or set) of each test row.

    Args:
        item: the dataset with a fitted model.
        confidence: share of rows that the intervals should cover.
            Defaults to 0.9.
        cv: number of folds of the training rows. Defaults to 5.
        **kwargs: not used.

    Returns:
        One row for each test row, with "actual", "prediction", "lower"
            and "upper" (or "set" and "size"), and "covered".

    """
    sklearn_base = importlib.import_module('sklearn.base')
    model = _model(item)
    columns = (
        utilities.feature_names(model, item.data.columns) or item.features)
    rows = item.y_test.index if item.is_split else item.data.index
    train = item.y_train.index
    estimator = sklearn_base.clone(model)
    actual = item.y.loc[rows]
    if item.task == 'regress':
        regression = utilities.import_tool('mapie.regression')
        conformal = regression.CrossConformalRegressor(
            estimator,
            confidence_level = confidence,
            cv = cv,
            random_state = item.seed)
        conformal.fit_conformalize(
            item.data.loc[train, columns], item.y_train)
        predicted, intervals = conformal.predict_interval(
            item.data.loc[rows, columns])
        lower = intervals[:, 0, 0]
        upper = intervals[:, 1, 0]
        return pd.DataFrame({
            'actual': actual,
            'prediction': predicted,
            'lower': lower,
            'upper': upper,
            'covered': (actual >= lower) & (actual <= upper)},
            index = rows)
    classification = utilities.import_tool('mapie.classification')
    conformal = classification.CrossConformalClassifier(
        estimator,
        confidence_level = confidence,
        cv = cv,
        random_state = item.seed)
    conformal.fit_conformalize(item.data.loc[train, columns], item.y_train)
    predicted, sets = conformal.predict_set(item.data.loc[rows, columns])
    classes = np.unique(np.asarray(item.y_train))
    members = [
        [c for c, inside in zip(classes, row, strict = True) if inside]
        for row in sets[:, :, 0]]
    return pd.DataFrame({
        'actual': actual,
        'prediction': predicted,
        'set': [', '.join(str(c) for c in m) for m in members],
        'size': [len(m) for m in members],
        'covered': [
            a in m for a, m in zip(actual, members, strict = True)]},
        index = rows)

    def evaluate(self, item: base.Dataset, **kwargs: Any) -> pd.DataFrame:
    """Returns the confusion matrix.

    Args:
        item: the dataset with a fitted classifier.
        **kwargs: not used.

    Returns:
        One row for each actual class and one column for each predicted
            class.

    """
    metrics = importlib.import_module('sklearn.metrics')

        columns = pd.Index(classes, name = 'predicted'))

    def apply(
    self,
    item: base.Dataset,
    *,
    visualize: bool = False,
    **kwargs: Any) -> base.Dataset:
    """Adds the table from `evaluate` to the tables of `item`.

    def evaluate(
    self,
    item: base.Dataset,
    top: int = 20,
    **kwargs: Any) -> pd.DataFrame:
    """Returns eli5's table of the model's weights.

    Args:
        item: the dataset with a fitted model.
        top: most weights to list. Defaults to 20.
        **kwargs: not used.

        IncompatibleTechniqueError: if eli5 cannot explain the model.

    eli5 = utilities.import_tool('eli5')
    model = _model(item)
    if isinstance(model, models.LabelCoded):
        model = model.estimator

        utilities.feature_names(model, item.data.columns)
        or item.features)]
    table: pd.DataFrame | None = eli5.explain_weights_df(
        model, feature_names = names, top = top)
    if table is None:
        message = (
            f'eli5 cannot explain the weights of {type(model).__name__}')
        raise base.IncompatibleTechniqueError(message)
    return table

    FactorAnalysis(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Evaluator

    The hidden factors that explain the correlations of the features.

    statsmodels' factor analysis of the features that the model learned from (the real training rows). The table has a row for each feature, with its loading on each factor, its communality (the share of its variance that the factors explain), and its uniqueness (the rest). By default, there is a factor for each eigenvalue of the features' correlations above 1 (Kaiser's rule), and the loadings are rotated by varimax.

    Wraps

    statsmodels.multivariate.factor.Factor from statsmodels.

    def evaluate(
    self,
    item: base.Dataset,
    *,
    factors: int | None = None,
    method: str = 'pa',
    rotation: str | None = 'varimax',
    columns: Sequence[str] | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Returns the loading of each feature on each factor.

    Args:
        item: the dataset.
        factors: number of factors. Defaults to `None`, which uses
            Kaiser's rule.
        method: "pa" (principal axes) or "ml" (maximum likelihood).
            Defaults to "pa".
        rotation: how statsmodels rotates the loadings, such as
            "varimax", "quartimax", "promax", or "oblimin", or `None`
            (or "none") to leave them unrotated. Defaults to "varimax".
        columns: the columns to analyze. Defaults to `None`, which uses
            the numeric and boolean features.
        **kwargs: not used.

    Returns:
        One row for each feature, with a "factor_{n}" column for each
            factor, "communality", and "uniqueness".

    """
    factor = utilities.import_tool('statsmodels.multivariate.factor')
    data = _numbers(item, columns, self.name)
    count = factors or _kaiser(data)
    results = factor.Factor(
        data, n_factor = count, method = method, missing = 'drop').fit()
    if rotation not in {None, 'none'} and count > 1:
        results.rotate(rotation)
    names = [f'factor_{n}' for n in range(1, count + 1)]
    table = pd.DataFrame(
        np.asarray(results.loadings), index = data.columns, columns = names)
    table['communality'] = np.asarray(results.communality)
    table['uniqueness'] = np.asarray(results.uniqueness)
    return table

    def evaluate(self, item: base.Dataset, **kwargs: Any) -> pd.DataFrame:
    """Returns the importance of each feature, largest first.

    Args:
        item: the dataset with a fitted model.
        **kwargs: not used.

    Raises:
        IncompatibleTechniqueError: if the model does not report the
            importance of its features.

    Returns:
        One row for each feature, with an "importance" column.

    """
    model = _model(item)
    importances = getattr(model, 'feature_importances_', None)
    if importances is None and hasattr(model, 'term_importances'):
        # An Explainable Boosting Machine reports the importance of each
        # term (a feature or a pair of features).
        return _importance_table(
            [str(n) for n in model.term_names_],
            np.asarray(model.term_importances()))
    if importances is None:
        coefficients = getattr(model, 'coef_', None)
        if coefficients is None:
            message = (
                f'{type(model).__name__} does not report the importance of '
                f'its features: use permutation_importance instead'
            )
            raise base.IncompatibleTechniqueError(message)
        importances = np.abs(np.atleast_2d(coefficients)).mean(axis = 0)
    features = (
        utilities.feature_names(model, item.data.columns) or item.features)
    coefficients = getattr(model, 'coefficients', None)
    if len(np.ravel(importances)) != len(features) and callable(coefficients):
        # A model that drops features (such as pyfixest's, which drops
        # collinear ones) has a coefficient only for the others.
        table = coefficients().dropna(subset = ['coefficient'])
        kept = [f for f in features if f in table.index]
        return _importance_table(
            kept, np.abs(table.loc[kept, 'coefficient'].to_numpy(float)))
    return _importance_table(features, np.asarray(importances))

    def evaluate(
    self,
    item: base.Dataset,
    *,
    components: int | None = None,
    standardize: bool = True,
    columns: Sequence[str] | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Returns the eigenvalue and share of the variance of each component.

    Args:
        item: the dataset.
        components: number of components. Defaults to `None`, which uses
            one for each column.
        standardize: whether to give each column a standard deviation of
            1 first, so that the columns with the largest values do not
            dominate. Defaults to `True`.
        columns: the columns to analyze. Defaults to `None`, which uses
            the numeric and boolean features.
        **kwargs: not used.

    Returns:
        One row for each component, with its "eigenvalue" (of the
            correlations of the columns, or of their covariances if
            `standardize` is `False`), the "share" of the variance that
            it explains, and the "cumulative" share of it and the
            components before it.

    """
    pca = utilities.import_tool('statsmodels.multivariate.pca.PCA')
    data = _numbers(item, columns, self.name)
    results = pca(
        data,
        ncomp = components,
        standardize = standardize,
        missing = 'drop-row')
    count = len(results.eigenvals)
    names = [f'component_{n}' for n in range(1, count + 1)]
    # statsmodels' eigenvalues are multiplied by the number of rows, and
    # the R² of the first n components is the share of the variance that
    # they explain together.
    rows = len(results.factors)
    cumulative = np.asarray(results.rsquare)[1:count + 1]
    item.tables[f'{self.name}_loadings'] = pd.DataFrame(
        np.asarray(results.loadings), index = data.columns, columns = names)
    return pd.DataFrame({
        'eigenvalue': np.asarray(results.eigenvals) / rows,
        'share': np.diff(cumulative, prepend = 0.0),
        'cumulative': cumulative},
        index = names)

    RegressionTable(contents=None, name='', parameters=dict(), title=None, digits=3, stars=(0.1, 0.05, 0.01), style='stata', table=None, estimates=None, statistics=None) dataclass ¶

    Bases: _Published, Evaluator

    The estimates of every model side by side, ready to publish.

    Like the regression tables of Stata, R, and statsmodels, it has a column for each model and two rows for each feature: its estimate, with stars for its p-value, and below it, its standard error in parentheses. The models are the branches of the most recent experiment, or the final model if the data did not come from one. Rows below the estimates describe each model: the kind of estimates, the number of observations that it learned from, and its cross-validated metrics.

    A model that reports its coefficients and their statistics (the statsmodels and pyfixest models, such as ols, logit_sm, glm, and fixest) is shown with them. Every other model is shown with the average marginal effect (AME) of each feature: the average change in the prediction (or in the predicted probability of each class, for a classifier) for a one-unit increase in the feature. These are models without coefficients (such as random_forest or xgboost) and the scikit-learn linear models, whose coefficients have no standard errors. The AME of a linear regression is its coefficient. For each training row, a feature is moved up and down by "step" of its standard deviations (0.1 by default), or from its lower to its higher value if it has only two. The standard error and 95% confidence interval of an AME come from refitting the model to "simulations" bootstrap samples of the training rows (100 by default), and its p-value comes from the normal distribution. Set "marginal" to true to show marginal effects for every model, which puts every column on the same scale.

    Features that form a set, such as the dummy variables of one category with its reference left out (a victim's relationship to an offender: "family", "partner", or "stranger", against "unknown"), cannot be moved one at a time: setting "family" to 1 in a row whose "stranger" is 1 makes a row that cannot happen. Name them in "sets" (in settings, as "family, partner, stranger; under_12, teen", with sets separated by semicolons) and the AME of each member is the average change in the prediction from the reference (every member 0) to that member alone (it 1, the others 0). The members of a set must have two values each, and members that are not features of a model are left out of its set.

    The metrics are cross-validated on the training rows, never scored on the rows that the model learned from. They are the "cv_{metric}" metrics of a validator that the analysis already ran, or else they come from the validator named by "validator" (stratified_k_fold to classify and k_fold to regress, by default).

    A marginal effect describes the model, not the world. It is the model's estimated effect if every other feature is held fixed, so it is only causal if the features are (see the inferers to estimate a causal effect). It can mislead when features are correlated, since moving one while holding the others fixed makes rows unlike any real one. The bootstrap treats rows as independent, so its standard errors are too small for rows that are correlated within groups or over time.

    The estimates are stored in the dataset's tables under the technique's name, with one row for each model and feature, and the rows below them are stored as "{name}_statistics". The table can be saved in the same formats as a scorecard (csv, Markdown, LaTeX, HTML, Word, or an image). In the "stata" style (the default), Word documents, images, and to_text look like Stata's output of regress: a block for each model, with a description of the model and its statistics at the top and a table of its estimates below them ("Coef." or "dy/dx", "Std. Err.", "t" or "z", its p-value, and its 95% confidence interval), set in a monospaced font between rules. In the "columns" style, they put the models side by side, as csv, Markdown, LaTeX, and HTML always do (like Stata's esttab). Make one from a dataset, an applied project, or several datasets with create.

    Wraps
    • sklearn.base.clone from scikit-learn, to refit each model to bootstrap samples.
    • scipy.stats.norm from SciPy, for the p-values of marginal effects.
    • docx.Document from python-docx, for to_word.
    • matplotlib.figure.Figure from matplotlib, for to_image.

            lines.append('-' * line.width)
        elif line.kind == 'cross':
            lines.append(
                '-' * line.bar + '+' + '-' * (line.width - line.bar - 1))
        else:
            lines.append(line.text.rstrip())
    text = '\n'.join(lines) + '\n'
    if path is not None:
        pathlib.Path(path).write_text(text, encoding = 'utf-8')
    return text

    def to_word(self, path: pathlib.Path | str) -> pathlib.Path:
    """Saves the table in a Word document.

    In the "stata" style, the document has the heading and, for each
    model, a borderless table of its description and statistics and a
    table of its estimates with Stata's rules (above and below the
    header, below the last term, and after the terms), set in Courier
    New. In the "columns" style, the models are side by side, as in a
    scorecard.

    Args:
        path: file to save the document in (usually ending in ".docx").

    Returns:
        The path of the document.

    """
    if not self._stata_style():
        return super().to_word(path)
    docx = utilities.import_tool('docx')
    alignment = utilities.import_tool('docx.enum.text.WD_ALIGN_PARAGRAPH')
    points = utilities.import_tool('docx.shared.Pt')
    document = docx.Document()
    normal = document.styles['Normal']
    normal.font.name = 'Courier New'
    normal.font.size = points(8)
    normal.paragraph_format.space_after = points(0)
    document.add_heading(self.heading, level = 2)
    for model in self._models():
        left, right = self._stata_header(model)
        header = document.add_table(
            rows = max(len(left), len(right)), cols = 2)
        for row, text in enumerate(left):
            header.cell(row, 0).text = text
        for row, text in enumerate(right):
            header.cell(row, 1).text = text
            header.cell(row, 1).paragraphs[0].alignment = alignment.RIGHT
        document.add_paragraph()
        rows = self._stata_rows(model)
        grid = document.add_table(rows = len(rows), cols = 7)
        for number, values in enumerate(rows):
            for column, value in enumerate(values):
                cell = grid.cell(number, column)
                cell.text = value
                cell.paragraphs[0].alignment = alignment.RIGHT
            edges = ['right'] if number else ['top', 'bottom']
            if number == len(rows) - 1 and number:
                edges.append('bottom')
            _border(grid.cell(number, 0), [*edges, 'right'])
            for column in range(1, 7):
                _border(
                    grid.cell(number, column),
                    [e for e in edges if e != 'right'])
        # The interval's header spans its two columns, as in Stata.
        interval = grid.cell(0, 5).merge(grid.cell(0, 6))
        interval.text = rows[0][5]
        interval.paragraphs[0].alignment = alignment.CENTER
        document.add_paragraph()
    notes = self._stata_notes()
    if notes:
        document.add_paragraph(notes)
    path = pathlib.Path(path)
    document.save(str(path))
    return path

    Scorecard(contents=None, name='', parameters=dict(), title=None, digits=3, table=None, summary=None) dataclass ¶

    Bases: _Published, Evaluator

    The results of every branch of an analysis, ready to publish.

    A scorecard has one row for each branch of the most recent experiment (each combination of techniques that it tried): its rank, the technique used at each step, and every standard metric for the task, computed from that branch's own predictions. If the data did not come from an experiment, it has one row for the final model and the techniques that made it. The table is stored in the dataset's tables under the technique's name, and the final model's metrics are stored in its metrics.

    A scorecard can be saved as a csv file (to_csv), a Markdown table (to_markdown), a LaTeX table (to_latex), an HTML table (to_html, which needs great_tables), a Word document (to_word, which needs python-docx), or an image (to_image, which needs matplotlib), or in several at once (export). If the dataset has groups and a label of two classes, fairness metrics are included. Make one from a dataset or an applied project with create, or use Project.scorecard.

    Wraps
    • great_tables.GT from great_tables, for to_html.
    • docx.Document from python-docx, for to_word.
    • matplotlib.axes.Axes.table from matplotlib, for to_image.

    def evaluate(
    self,
    item: base.Dataset,
    metrics: Sequence[str] | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Returns the scorecard of `item`, which is also stored in `table`.

    Args:
        item: the dataset with a fitted model.
        metrics: names of the metrics to use. Defaults to `None`, which
            uses `defaults` for the task (with the experiment's criterion
            first, and the `fairness` metrics after them if the dataset
            has groups and two classes). Other metrics that the branches
            computed are added after them.
        **kwargs: not used.

    Returns:
        One row for each branch, best first, with a "rank" column, a
            column for each step, and a column for each metric.

    """
    branches = item.branches or [base.Branch(
        label = 'result', steps = self._history_steps(item), result = item)]
    names = self._metric_names(item, branches, metrics)
    extras = list(dict.fromkeys(
        name for branch in branches for name in branch.result.metrics
        if name not in names))
    rows = []
    for branch in branches:
        row: dict[str, Any] = dict(branch.steps)
        row.update(self._measure(branch.result, names))
        row.update({
            name: branch.result.metrics[name] for name in extras
            if name in branch.result.metrics})
        rows.append(row)
    steps = list(dict.fromkeys(k for b in branches for k in b.steps))
    table = pd.DataFrame(rows)
    columns = steps + [n for n in [*names, *extras] if n in table.columns]
    table = table.reindex(columns = columns)
    criterion = branches[0].criterion
    scores = [branch.score for branch in branches]
    if any(score is not None for score in scores):
        if criterion not in table.columns:
            table['score'] = scores
        # Sorts from best to worst. Ties keep the order of the branches.
        order = sorted(range(len(scores)), key = lambda i: _worst_first(
            scores[i]))
        table = table.iloc[order].reset_index(drop = True)
    table.insert(0, 'rank', range(1, len(table) + 1))
    self.table = table
    if item.branches:
        ranked = f' ranked by {criterion}' if criterion else ''
        self.summary = f'{len(branches)} branches{ranked}'
    else:
        self.summary = 'The final model'
    return table

    self,
    item: base.Dataset,
    rows: int = 200,

    **kwargs: Any) -> pd.DataFrame:
    """Returns the importance of each feature, largest first.

    Args:
        item: the dataset with a fitted model.
        rows: most rows to explain. Defaults to 200.
        background: most training rows to use as the background data.
            Defaults to 100.
        **kwargs: not used.

    Returns:
        One row for each feature, with an "importance" column.

    """
    shap = utilities.import_tool('shap')
    model = _model(item)
    # Columns that the model needs besides its features, such as the
    # fixed effects of a `fixest` model, are held at each row's own
    # values while its features are explained.
    others = _other_columns(model, item)
    if isinstance(model, models.LabelCoded):
        model = model.estimator
    train = item.x_train
    sample = train.sample(
        min(background, len(train)), random_state = item.seed)
    x = item.x_test if item.is_split else item.x
    x = x.head(rows)
    given = item.data.loc[x.index, others] if others else None
    explanation = _explain(shap, model, sample, x, item.task, given = given)
    values = np.asarray(explanation.values)
    if values.ndim == 3:  # noqa: PLR2004
        values = values[:, :, -1]
    item.fitted[self.name] = explanation
    return _importance_table(list(x.columns), np.abs(values).mean(axis = 0))
