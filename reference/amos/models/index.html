    amos.models ¶

    Techniques that fit models and make predictions.

    These are the techniques of the last step of the "analyst" stage. Each one wraps a model from scikit-learn, xgboost, lightgbm, catboost, GPBoost, InterpretML, TabPFN, statsmodels, pyfixest, Bambi, or PyMC. Most work for both tasks: random_forest, for example, is a random forest classifier when the label is classified and a random forest regressor when it is regressed. A model is fitted to the training rows and predicts the test rows (or every row, if the data has not been split). The fitted model, its predictions, and (for classifiers) its predicted probabilities are stored in the dataset.

    Every model accepts the parameters of the tool it wraps. It also accepts "search" ("grid", "random", or "optuna"), which searches for the best values of any parameter that is given as a list, using cross-validation on the training rows ("cv" folds, 5 by default, and "n_iter" draws for a random or Optuna search). A search scores a classifier by the Matthews correlation coefficient and a regression by R², unless "scoring" names another scorer (see utilities.default_scorer). If the dataset has groups, the folds of a search keep the rows of each group of its first group column together, as the group validators do.

    If "use_gpu" is true in the "general" section of the settings (see Dataset.use_gpu) and an NVIDIA GPU is found, the models that can be fitted on a GPU (catboost, lightgbm, tabpfn, and xgboost) are fitted on the first one. If a model cannot use the GPU (because its package was built without GPU support, for example), it warns and is fitted on the CPU instead. Every other model is fitted on the CPU, as every model is when "use_gpu" is false (the default).

    Bambi(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Model

    Fits a Bayesian regression (with random intercepts) with Bambi.

    Bambi writes the model from a formula, as R's brms does, with weakly informative priors, and PyMC samples its posterior. By default, the label is regressed on every feature, with a random intercept for each level of "groups" (by default, the dataset's first group, if it has one). Set "formula" to write the model yourself in Bambi's syntax (such as "outcome ~ age + (age|hospital)"), with the names of the columns. A label of two classes uses the "bernoulli" family by default and a number the "gaussian" (set "family" to "poisson" for counts, for example). Set "draws", "tune", and "chains" for the sampler. Sampling takes longer than fitting most models, so the sampler's defaults are modest.

    The coefficients' posterior means, standard deviations, and 95% credible intervals are stored in the dataset's tables as "{name}_coefficients", and those of the standard deviations of the random effects as "{name}_random_effects". The predictions are posterior means. A row of a group that the model has not seen is predicted over the random effects that a new group could have.

    self,
    item: base.Dataset,
    search: str | None = None,
    cv: int = 5,
    n_iter: int = 10,
    scoring: str | None = None,
    **kwargs: Any) -> base.Dataset:
    """Fits the model and stores the posteriors of its random effects.

    Args:
        item: the dataset to model.
        search: as for `Model.apply`.
        cv: as for `Model.apply`.
        n_iter: as for `Model.apply`.
        scoring: as for `Model.apply`.

    item = super().apply(
        item,
        search = search,
        cv = cv,
        n_iter = n_iter,
        scoring = scoring,
        **_with_groups(item, kwargs))

    return item

    BayesianAdditiveTrees(m=50, alpha=0.95, beta=2.0, likelihood='normal', draws=1000, tune=1000, chains=2, cores=1, random_state=None) dataclass ¶

    Adapts PyMC's Bayesian additive regression trees (BART) to scikit-learn.

    BART is a sum of m small trees, each with a prior that keeps it shallow, whose posterior PyMC samples (with pymc-bart's particle Gibbs sampler for the trees, and NUTS for any other parameter). Like a random forest, it needs no scaling and finds interactions and curves itself, and its posterior says how sure it is of each prediction. With the "normal" likelihood the trees are the mean of a number (with an estimated standard deviation), with "bernoulli" they are the log odds of the second of two classes, and with "poisson" the log of the mean of counts. The predictions are the posterior means.

    A fitted PyMC model cannot be pickled, so the adapter keeps the sampled trees of each chain, and rebuilds pymc-bart's sampler of them when it predicts. The importance of each feature is the share of the splits of the trees on it.

    Wraps
    • pymc_bart.BART from pymc-bart, for the trees.
    • pymc.sample from PyMC, to sample their posterior.

    def fit(self, x: pd.DataFrame, y: pd.Series) -> BayesianAdditiveTrees:
    """Samples the posterior of the trees.

    Args:
        x: features.
        y: labels.

    Raises:
        ValueError: if the likelihood is not known, or a classifier's
            label does not have two classes.

    Returns:
        This adapter.

    """
    pm = utilities.import_tool('pymc')
    bart = utilities.import_tool('pymc_bart')
    if self.likelihood not in _BART_LIKELIHOODS:
        message = (
            f'the likelihood of BART must be one of '
            f'{sorted(_BART_LIKELIHOODS)}, not {self.likelihood!r}')
        raise ValueError(message)
    self.feature_names_in_ = np.asarray(x.columns)
    features = np.ascontiguousarray(x.to_numpy(dtype = float))
    target = np.asarray(y)
    if self.is_classifier:
        self.classes_, target = _two_classes(
            target, 'BART with the "bernoulli" likelihood')
    target = target.astype(float)
    with utilities.preserved_logging(), pm.Model():
        trees = bart.BART(
            'mu', features, target,
            m = self.m, alpha = self.alpha, beta = self.beta)
        if self.likelihood == 'normal':
            sigma = pm.HalfNormal('sigma', float(np.std(target)) or 1.0)
            pm.Normal('y', trees, sigma, observed = target)
        elif self.likelihood == 'bernoulli':
            pm.Bernoulli('y', logit_p = trees, observed = target)
        else:
            pm.Poisson('y', mu = pm.math.exp(trees), observed = target)
        posterior = pm.sample(
            self.draws,
            tune = self.tune,
            chains = self.chains,
            cores = self.cores,
            random_seed = self.random_state,
            progressbar = False)
    operation = trees.owner.op
    self.trees_ = list(operation.all_trees)
    self._outputs = int(operation.n_outputs)
    self._samplers = None
    # pymc-bart sorts the shares from the largest, and names each by its
    # position (it does not sort labels that it is given).
    shares, labels = bart.get_variable_inclusion(posterior, features)
    importances = np.zeros(features.shape[1])
    importances[[int(label) for label in labels]] = shares
    self.feature_importances_ = importances
    return self

    Adapts Bambi's Bayesian (mixed) regressions to scikit-learn.

    Bambi writes a PyMC model from a formula, as R's lme4 and brms do, with weakly informative priors, and samples its posterior with PyMC's NUTS. Without a formula, the label is regressed on every feature, with a random intercept for each level of each of groups (as "label ~ x0 + x1 + (1|group)").     GaussianProcessBoosting(groups=None, coordinates=None, likelihood='gaussian', cov_function='matern', gp_parameters=None, **parameters) ¶

    Adapts GPBoost's trees with random effects to scikit-learn.

    GPBoost boosts trees of the features, as LightGBM does, together with a model of the random effects of rows that are not independent: a random intercept for each level of each of groups (such as each school), a Gaussian process over coordinates (such as a latitude and a longitude), or both. The trees and the variances of the random effects are estimated together, so the trees learn the effects of the features apart from what the rows of a group (or of nearby places) share.

Without the columns of groups and coordinates (as when a critic passes only the features), every row is predicted by the trees alone, as if it were of an unseen group.     def apply(
    self,
    item: base.Dataset,
    search: str | None = None,
    cv: int = 5,
    n_iter: int = 10,
    scoring: str | None = None,
    **kwargs: Any) -> base.Dataset:
    """Fits the model to the training rows and predicts the test rows.

    Args:
        item: the dataset to model. It must have a label.
        search: "grid", "random", or "optuna" to search for the best
            values of any parameter given as a list. Defaults to `None`,
            which does not search (and passes lists to the model as they
            are).
        cv: number of cross-validation folds for a search, which keep
            the rows of each of the dataset's first groups together if
            it has groups. Defaults to 5.
        n_iter: number of combinations to try in a random or Optuna
            search. Defaults to 10.
        scoring: scikit-learn scorer for a search (such as "roc_auc").
            Defaults to `None`, which uses the Matthews correlation
            coefficient to classify and R² to regress (see
            `utilities.default_scorer`).
        **kwargs: parameters for the model. Any "plots", "evaluators",
            or "inferers" (the techniques that replace a workflow's for
            this model) are left out.

    Returns:
        The dataset, with the fitted `model`, `predictions`, and (for a
            classifier) `probabilities`.

    """
    # The techniques that replace a workflow's plots, evaluators, and
    # inferers for this model are not parameters of its tool (see
    # `base.using_model_specific_techniques`).
    kwargs = {
        k: v for k, v in kwargs.items()
        if k not in base._MODEL_SPECIFIC_GENRES}
    task = self._check_task(item)
    scoring = scoring or utilities.default_scorer(task)
    extras = self._extra_columns(item, kwargs)
    self._check_features(item, extras)
    path = self._choose_tool(task)
    tool = utilities.import_tool(path)
    fixed, space = (
        (kwargs, {}) if search is None
        else utilities.search_space(kwargs, search))
    space = utilities.accepted_parameters(tool, space)
    columns = [c for c in item.features if c not in extras] + extras
    y = item.y_train
    x = item.data.loc[y.index, columns]
    fit = functools.partial(
        self._fit,
        item,
        tool,
        x,
        y,
        task = task,
        fixed = fixed,
        space = space,
        search = search,
        cv = cv,
        n_iter = n_iter,
        scoring = scoring)
    gpu = self._uses_gpu(item)
    try:
        estimator = fit(gpu = gpu)
    # Anything that stops a model from using the GPU (such as a package
    # built without GPU support, a GPU that is too old for it, or too
    # little memory) means fitting it on the CPU instead. An error that
    # has nothing to do with the GPU is raised again by the CPU's fit.
    except Exception as error:
        if not gpu:
            raise
        warnings.warn(
            f'{self.name!r} could not be fitted on the GPU, so it was '
            f'fitted on the CPU instead: {error}',
            category = base.AmosWarning,
            stacklevel = 2)
        estimator = fit(gpu = False)
    item.model = estimator
    self._predict(item, estimator, task, columns)
    if hasattr(estimator, 'coefficients'):
        item.tables[f'{self.name}_coefficients'] = estimator.coefficients()
    item.record(
        self.name,
        role = 'model',
        tool = utilities.describe_tool(path),
        task = task,
        parameters = utilities.parameters_of(estimator),
        search = search,
        rows = len(x))
    return item

    """Fits the model.

    Args:
        x: features and the event column.
        y: the time until the event or censoring.

        'statsmodels.duration.hazard_regression')

    self.feature_names_in_ = np.asarray(data.columns)
    status = None

        np.asarray(y, dtype = float), data.to_numpy(), status = status,

        alpha = self.penalizer, L1_wt = 0.0).params
    # statsmodels gives no standard errors for a penalized fit. They come
    # from the curvature of the penalized log likelihood.
    information = -model.hessian(params) + (
        len(data) * self.penalizer * np.eye(len(params)))
    self.results = regression.PHRegResults(
        model, params, np.linalg.inv(information))
    return self

    def predict(self, x: pd.DataFrame) -> np.ndarray:
    """Returns the expected time until the event.

    The expected time is the area under a row's survival curve, up to the
    longest time in the training rows.

    Args:
        x: features (and, optionally, the event column).

    Returns:
        The expected times.

    """
    features = self._features(x).astype(float).to_numpy()
    times, hazards, _ = self.results.baseline_cumulative_hazard[0]
    end = np.max(self.results.model.endog)
    # The survival curves are steps that start at 1 and drop at each time
    # with an event in the training rows.
    widths = np.diff(np.concatenate([[0.0], times, [end]]))
    risks = np.exp(features @ np.asarray(self.results.params))
    survival = np.exp(-np.outer(risks, np.concatenate([[0.0], hazards])))
    return survival @ widths

    Fits Bayesian additive regression trees (BART) with PyMC.

    A sum of small trees (50 by default; set "m" for more), each held shallow by its prior, whose posterior PyMC samples. Like a random forest, it needs no scaling and finds curves and interactions itself, and its posterior says how sure it is of each prediction. A label of two classes uses the "bernoulli" likelihood (the trees are its log odds) and a number the "normal" (set "likelihood" to "poisson" for counts). The predictions are posterior means, and the importance of each feature is the share of the trees' splits on it. Set "draws", "tune", and "chains" for the sampler. Sampling trees is slow on large data.

    Wraps
    • pymc_bart.BART from pymc-bart, for the trees.
    • pymc.sample from PyMC, to sample their posterior.

    def coefficients(self) -> pd.DataFrame:
    """Returns the coefficients and their statistics.

    Returns:
        One row for each coefficient, with its "coefficient",
            "standard_error", "statistic", "p_value", "ci_lower", and
            "ci_upper". The coefficients of an "mnlogit" are named
            "{feature} ({class})", for each class other than the
            reference. A "binomial_bayes_mixedglm" reports the
            mean and standard deviation of each coefficient's posterior
            and its 95% credible interval, and no p-values. A feature
            that was left out (see `dropped_`) has an empty row, and the
            statistics are missing if statsmodels could not find the
            covariance of the coefficients.

    """
    results = self.results
    labels = None
    if self.kind == 'binomial_bayes_mixedglm':
        means = self._params()
        deviations = pd.Series(
            np.asarray(results.fe_sd), index = means.index)
        # Variational Bayes gives each coefficient a normal posterior.
        table = pd.DataFrame({
            'coefficient': means,
            'standard_error': deviations,
            'statistic': means / deviations,
            'p_value': np.nan,
            'ci_lower': means - 1.96 * deviations,
            'ci_upper': means + 1.96 * deviations})
    else:
        params = results.params
        columns = [params] + [
            _statistic(results, name, params)
            for name in ('bse', 'tvalues', 'pvalues')]
        try:
            intervals = np.asarray(results.conf_int())
        except ValueError:
            intervals = np.full((params.size, 2), np.nan)
        if isinstance(params, pd.DataFrame):
            labels = [str(c) for c in self.levels_[1:]]
            columns = [_by_class(frame, labels) for frame in columns]
        # The intervals are in the same order as the coefficients (class
        # by class, for an mnlogit).
        table = pd.DataFrame({
            'coefficient': columns[0],
            'standard_error': columns[1],
            'statistic': columns[2],
            'p_value': columns[3],
            'ci_lower': intervals[:, 0],
            'ci_upper': intervals[:, 1]})
    empty = list(self.dropped_) if labels is None else [
        f'{name} ({label})' for label in labels for name in self.dropped_]
    return table.reindex([*table.index, *empty])

    output = self.output

    def search_folds(
    item: base.Dataset,
    x: pd.DataFrame,
    y: pd.Series,
    cv: int) -> int | list[tuple[np.ndarray, np.ndarray]]:
    """Returns the folds of a search, which keep groups together.

    When rows are not independent (such as the ratings of several reviewers of
    one product), a fold that splits a group puts rows that are nearly copies of
    each other on both sides, so the search scores the model on rows it has
    partly seen. So if the dataset has groups, each group of its first group
    column is kept wholly in one fold, as the group validators keep them: with
    the classes balanced across folds for a classifier, and in folds of about
    equal size for a regression. A row with a missing group is a group of its
    own.

    Wraps:
        - [`sklearn.model_selection.StratifiedGroupKFold`](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedGroupKFold.html)
          from scikit-learn, for a classifier.
        - [`sklearn.model_selection.GroupKFold`](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupKFold.html)
          from scikit-learn, for a regression.

    Args:
        item: the dataset being modeled.
        x: the training rows of the columns the model uses.
        y: the training labels.
        cv: number of cross-validation folds.

    Returns:
        `cv`, if the dataset has no groups, or else the training and test
            positions of each fold.

    """
    if not item.groups:
        return cv
    model_selection = importlib.import_module('sklearn.model_selection')
    groups = item.data.loc[x.index, item.groups[0]].astype(object)
    missing = groups.isna()
    groups[missing] = [f'__row__{label}' for label in groups.index[missing]]
    codes = pd.factorize(groups)[0]
    if item.task == 'classify':
        splitter = model_selection.StratifiedGroupKFold(
            n_splits = cv, shuffle = True, random_state = item.seed)
    else:
        splitter = model_selection.GroupKFold(n_splits = cv)
    return list(splitter.split(x, y, codes))
