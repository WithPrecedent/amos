    Techniques that choose other techniques to suit the data.

    Name "auto" in place of a technique, and amos chooses the techniques that suit the data when the workflow reaches it. "auto" works in a step that fills missing values, encodes, samples, models, evaluates, or plots (the kind of step is found from its name, such as "impute", "encode", "sample", "model", or "plot", or from the name of a worker such as "critic" or "artist"), or name the chooser yourself: auto_imputer, auto_encoder, auto_sampler, auto_model, auto_evaluator, or auto_plot.

    [analyst]
steps = split, impute, encode, sample, model
split_techniques = stratified
impute_techniques = auto
encode_techniques = auto
sample_techniques = auto
model_techniques = auto

[critic]
techniques = auto

[artist]
techniques = auto

    Each chooser first profiles the real training rows (see profile): the balance of the classes, the distribution of a regression's errors, whether the label is counts, missing values, the kinds and scales of the features, and how collinear they are. It then rules out the techniques whose needs or assumptions the data does not meet, and records why in a table in the dataset's tables (named for the chooser, such as "auto_model"), with a row for each technique it considered. The profile and the choice are also in the dataset's history, so a paper can report how each technique was chosen.

    Contents

    Profile: what the training rows are like. profile: returns the profile of a dataset. resolve: tells each "auto" technique in a workflow which kind of technique to choose, from the name of its step or worker. Chooser: base class for techniques that choose other techniques. Auto: chooses the techniques of the step that it is in. AutoEncoder: encodes each categorical feature in the way that suits how many levels it has, and dates by their parts. AutoEvaluator: applies the evaluators that suit the task and the model. AutoImputer: fills missing values in the ways that suit the features, or not at all. AutoModel: rules out models whose assumptions the data does not meet, cross-validates the rest, and fits the best. AutoPlot: draws the figures that suit the data and the model. AutoSampler: chooses a sampler that suits the balance of the classes and the features, or none.

    AutoEncoder(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Chooser

    Encodes each categorical feature in the way that suits it.

    Models need numbers, so every feature of text or categories is encoded, each with the first of these that suits it (the levels of a feature are counted in the training rows):

    • one_hot for a feature with 15 levels or fewer ("levels"): a dummy variable for each level, which every model can use and whose coefficients are easy to read.
    • tfidf (with skrub) for free text: a feature with more levels whose typical value has 3 words or more. It encodes the words of each value.
    • target (with category_encoders) for a feature with more levels, if the label has two classes or is regressed: the mean label of each level, shrunk toward the overall mean for rare levels. Dummy variables for so many levels would make the data wide and each level rare.
    • count (with category_encoders) for a feature with more levels and a label of more classes (or none): how often each level is in the training rows.
    • one_hot with at most "levels" columns for a feature with more levels, if category_encoders is not installed. Its rarest levels share one column.

    Dates are split into their parts (year, month, day, and so on) by date_parts, with skrub.

    The table (named "auto_encoder") has a row for each encoder considered (or a row for "none"), with whether it was chosen and why (or why not). The history records the encoder of each feature.

    def apply(
    self,
    item: base.Dataset,
    choices: Sequence[str] | str | None = None,
    levels: int = _LEVELS,
    **kwargs: Any) -> base.Dataset:
    """Encodes the categorical features and dates of `item`.

    Args:
        item: the dataset to encode.
        choices: names of the encoders to choose from, in the order to
            prefer them, for every feature. Defaults to `None`, which uses
            those in `_ENCODERS` for each kind of feature.
        levels: most levels of a feature for dummy variables. Defaults to
            15.
        **kwargs: parameters for the encoders (such as "drop" for
            `one_hot`). Each encoder uses those it accepts.

    Raises:
        ValueError: if no encoder suits a feature.

    Returns:
        The dataset, with its categorical features and dates encoded.

    """
    found = profile(item)
    rows = item.real_train_rows
    counts = {
        column: int(item.data.loc[rows, column].nunique())
        for column in item.categoricals}
    encoders: dict[str, str] = {}
    reasons: dict[str, str] = {}
    for column in item.dates + item.categoricals:
        kind = (
            'dates' if column in item.dates
            else _feature_kind(item.data.loc[rows, column], levels))
        names = (
            _ENCODERS[kind] if choices is None
            else camina.listify(choices))
        tried = {name: _screen_encoder(name, kind, found) for name in names}
        chosen = next(
            (name for name, reason in tried.items() if reason is None),
            None)
        if chosen is None:
            message = (
                f'{self.name!r} found no encoder for {column!r}: '
                + '; '.join(f'{n} {r}' for n, r in tried.items()))
            raise ValueError(message)
        encoders[column] = chosen
        for name, reason in tried.items():
            if name == chosen:
                break
            reasons.setdefault(name, cast('str', reason))
    if not encoders:
        table = pd.DataFrame(
            {'chosen': [True],
             'reason': ['there are no categorical features or dates']},
            index = pd.Index(['none']))
        self._record(item, table, found, [])
        return item
    groups: dict[str, list[str]] = {}
    for column, name in encoders.items():
        groups.setdefault(name, []).append(column)
    for name, columns in groups.items():
        parameters = dict(kwargs)
        if any(counts.get(column, 0) > levels for column in columns):
            parameters.setdefault('max_categories', levels)
        _borrow(name)().apply(item, columns = columns, **parameters)
    explained = {
        name: _encoder_suits(name, columns, counts, levels, found)
        for name, columns in groups.items()}
    for name, reason in reasons.items():
        explained.setdefault(name, reason)
    table = pd.DataFrame(
        {'chosen': [name in groups for name in explained],
         'reason': list(explained.values())},
        index = pd.Index(list(explained)))
    self._record(item, table, found, list(groups), encoders = encoders)
    return item

    AutoEvaluator(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Chooser

    Applies the evaluators that suit the task and the model.

    It needs the predictions of a fitted model, and applies those of these that suit it, in this order:

    • scorecard, which compares every branch (or the model) on every metric.
    • classification_report and confusion, for a classified label.
    • regression_table, for a model that reports coefficients with standard errors (such as ols, logit_sm, or fixest), unless the data came from an experiment. The table would have a column for each of its models, and estimate the effects of each model without coefficients by refitting it many times.
    • feature_importance, for a model with its own importances (or coefficients).
    • permutation_importance, which works for any scikit-learn model, when there is no regression table (which describes the features better).
    • shap_importance, for a model made of trees (with shap installed).
    • fairness, for a label of two classes with groups (with fairlearn installed).

    Apply it before auto_plot, which draws the importances it finds. Evaluators that cannot be applied are left out, with a warning, and the reason is in the table (named "auto_evaluator").

    self,
    item: base.Dataset,
    choices: Sequence[str] | str | None = None,
    **kwargs: Any) -> base.Dataset:
    """Applies the evaluators that suit `item`.

    Args:
        item: the dataset, with predictions.
        choices: names of the evaluators to choose from. Defaults to
            `None`, which uses every evaluator that suits the model.
        **kwargs: parameters for the evaluators (such as "n_repeats").
            Each evaluator uses those it accepts.

    Raises:
        ValueError: if there are no predictions.
        Exception: the error of the first evaluator, if none could be
            applied.

    Returns:
        The dataset, with the evaluators' tables and metrics.

    """
    if item.predictions is None:
        message = f'{self.name!r} needs the predictions of a fitted model'
        raise ValueError(message)
    found = profile(item)
    rows = _evaluators(item, found)
    if choices is not None:
        allowed = set(camina.listify(choices))
        rows = [row for row in rows if row[0] in allowed]
    table, applied = self._apply_each(item, rows, kwargs, done = 'applied')
    self._record(item, table, found, applied)
    return item

    AutoImputer(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Chooser

    Fills missing values in the ways that suit the features.

    Features without missing values are left alone, and so is a dataset without any. The numeric features with missing values are filled by the first of these that suits them:

    • iterative_impute, if a numeric feature misses more than 5% of its values in the training rows, there are at least two numeric features, and there are no more than 10,000 training rows. It models each feature from the others, which keeps their relationships better than filling every gap with one value.
    • median_impute, which fills each gap with the median of the training rows, which skewed values and outliers do not pull as they pull the mean.

    The categorical and boolean features are filled with their most common values by mode_impute.

    The table (named "auto_imputer") has a row for each imputer considered (or a row for "none"), with whether it was chosen and why (or why not).

    def apply(
    self,
    item: base.Dataset,
    choices: Sequence[str] | str | None = None,
    **kwargs: Any) -> base.Dataset:
    """Fills the missing values of the features of `item`.

    Args:
        item: the dataset to fill.
        choices: names of the imputers to choose from, in the order to
            prefer them. Defaults to `None`, which uses `_IMPUTERS`.
        **kwargs: parameters for the imputers. Each imputer uses those
            it accepts.

    Returns:
        The dataset, with its missing values filled.

    """
    found = profile(item)
    missing = [
        column for column in item.features
        if base._kind_of(item.data[column]) != 'dates'
        and bool(item.data[column].isna().any())]
    if not missing:
        table = pd.DataFrame(
            {'chosen': [True], 'reason': ['no feature has missing values']},
            index = pd.Index(['none']))
        self._record(item, table, found, [])
        return item
    shares = item.data.loc[item.real_train_rows, missing].isna().mean()
    kinds = {column: base._kind_of(item.data[column]) for column in missing}
    numeric = [c for c in missing if kinds[c] == 'numerics']
    most = float(shares[numeric].max()) if numeric else 0.0
    names = list(_IMPUTERS) if choices is None else camina.listify(choices)
    left = list(missing)
    filled: list[str] = []
    explained: dict[str, str] = {}
    for name in names:
        reason = _screen_imputer(
            name, len(item.numerics), len(item.real_train_rows), most)
        if reason is None:
            imputer = cast('type[transformers.Imputer]', _borrow(name))
            fills = imputer.kinds
            columns = [c for c in left if kinds[c] in fills]
            if columns:
                _borrow(name)().apply(item, columns = columns, **kwargs)
                left = [c for c in left if c not in columns]
                filled.append(name)
                explained[name] = _imputer_suits(name, columns, shares)
                continue
            reason = (
                f'suits the data, but {_names(filled, "and")} filled '
                f'the features it fills' if filled
                else 'no feature that it fills has missing values')
        explained[name] = reason
    if left:
        warnings.warn(
            f'{self.name!r} could not fill {left}: none of {names} fills '
            f'them',
            category = base.AmosWarning,
            stacklevel = 2)
    table = pd.DataFrame(
        {'chosen': [name in filled for name in explained],
         'reason': list(explained.values())},
        index = pd.Index(list(explained)))
    self._record(item, table, found, filled)
    return item

    AutoModel(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Chooser

    Fits the best of the models whose needs and assumptions the data meets.

    The models it considers (in the order it prefers them) are in _MODELS, with what each needs and assumes. It rules out the models that cannot do the task or use the features (missing values, categorical features, more features than rows, or features on very different scales for models that need them on similar scales), whose package is not installed, or whose assumptions the data does not meet:

    • linear assumes normal errors and features that are not collinear, so it is ruled out when the residuals of a least squares fit are materially skewed or heavy-tailed, or a feature's variance inflation factor is above 10.
    • naive_bayes assumes normal, independent features.
    • poisson assumes counts whose variance equals their mean, so it is ruled out for overdispersed counts (and for a label that is not counts). negative_binomial is for overdispersed counts and zero_inflated_poisson for counts with more zeros than a Poisson model expects.
    • robust_regression is for continuous errors with outliers, and ordinal_regression for three or more ordered classes.
    • logit, ridge, lasso, svm, knn, and neural_network need features on similar scales (put a scaler before them).
    • svm, knn, and neural_network are ruled out for data that is too large, too small, or too wide for them.

    It also knows the needs of ols (features that are not collinear), logit_sm and probit (two classes), and mnlogit (three or more classes), which report coefficients with standard errors, but it only considers them when they are named in "choices".

    The first candidates of the rest are cross-validated on the training rows (with stratified_k_fold for classification and k_fold for regression), and scored with metric. The model with the best score is fitted to the training rows, or, if simplest is true, the simplest model whose score is within one standard error of the best (the one-standard-error rule), which is easier to interpret and less likely to overfit.

    The table (named "auto_model") has a row for each model considered, with whether it was chosen, why it was ruled out (or what it suits), and its cross-validated score and standard error.

    def apply(
    self,
    item: base.Dataset,
    choices: Sequence[str] | str | None = None,
    candidates: int = 4,
    folds: int = 5,
    metric: str | None = None,
    *,
    simplest: bool = True,
    **kwargs: Any) -> base.Dataset:
    """Chooses a model and fits it to the training rows of `item`.

    Args:
        item: the dataset to model. It must have a label.
        choices: names of the models to choose from, in the order to
            prefer them. Defaults to `None`, which uses the models in
            `_MODELS` that can do the task.
        candidates: most models to cross-validate. Defaults to 4.
        folds: number of cross-validation folds. Defaults to 5. If it is
            less than 2 (or the rarest class has fewer than 2 rows), the
            first model that suits the data is chosen without
            cross-validation.
        metric: name of the metric to score each model with. Defaults to
            `None`, which uses "balanced_accuracy" for classification and
            "rmse" for regression.
        simplest: whether to choose the simplest model whose score is
            within one standard error of the best. Defaults to `True`.
        **kwargs: parameters for the models. Each model uses those it
            accepts.

    Raises:
        ValueError: if the dataset has no label, or no model suits it.

    Returns:
        The dataset, with the chosen model fitted and its predictions.

    """
    if item.task is None:
        message = f'{self.name!r} needs a dataset with a label'
        raise ValueError(message)
    found = profile(item)
    names = (
        [n for n in _MODELS if found.task in _tasks_of(n)]
        if choices is None else camina.listify(choices))
    reasons = {name: _screen_model(name, found) for name in names}
    suited = [name for name, reason in reasons.items() if reason is None]
    if not suited:
        message = (
            f'{self.name!r} found no model that suits the data: '
            + '; '.join(f'{n} {r}' for n, r in reasons.items()))
        raise ValueError(message)
    table = pd.DataFrame(
        {'chosen': False, 'reason': [
            _suits(name, found) if reason is None else reason
            for name, reason in reasons.items()],
         'score': np.nan, 'standard_error': np.nan},
        index = pd.Index(list(reasons)))
    tried = suited[:max(candidates, 1)]
    for name in suited[len(tried):]:
        table.loc[name, 'reason'] = (
            f'suits the data, but only the first {len(tried)} were '
            f'cross-validated')
    chosen = tried[0]
    details: dict[str, Any] = {}
    splits = _splits(item, folds)
    if len(tried) > 1 and splits > 1:
        metric = metric or (
            'balanced_accuracy' if item.task == 'classify' else 'rmse')
        scores = {}
        for name in tried:
            try:
                scores[name] = _cross_validate(
                    item, name, metric, splits, kwargs)
            # Any error means that the model cannot be fitted to this
            # data, so it is left out (and the reason is kept).
            except Exception as error:  # noqa: BLE001
                table.loc[name, 'reason'] = f'could not be fitted: {error}'
                warnings.warn(
                    f'{self.name!r} left out {name!r}, which could not be '
                    f'fitted: {error}',
                    category = base.AmosWarning,
                    stacklevel = 2)
                continue
            table.loc[name, ['score', 'standard_error']] = scores[name]
        if not scores:
            message = f'{self.name!r} could not fit any of {tried}'
            raise ValueError(message)
        better = getattr(_borrow(metric), 'greater_is_better', True)
        chosen = _best(scores, better = better, simplest = simplest)
        details = {'metric': metric, 'folds': splits}
    table.loc[chosen, 'chosen'] = True
    _borrow(chosen)().apply(item, **kwargs)
    self._record(item, table, found, [chosen], **details)
    return item

    Bases: Chooser

    Draws the figures that suit the data and the model.

    Before a model is fitted (or if "data" is true), it draws the data: the label, the numeric features (histograms, their correlations, box plots by class, and a pair plot if there are few), the categorical features, and where values are missing. After a model is fitted, it draws the model:

    • For classification, the confusion matrix and, if the model predicts probabilities, the ROC curve, the calibration curve (with enough test rows), and the precision-recall curve (if the classes are imbalanced, when it says more than the ROC curve).
    • For regression, the actual labels and the residuals against the predictions, and, for a model whose standard errors assume normal errors (such as ols), a Q-Q plot of the residuals and, for ols and glm, the influence of each row.
    • Coefficients with their confidence intervals, if there are any; the importance of the features, if the model has them; partial dependence for models that are not linear; SHAP values for models made of trees (with shap installed); a decision tree's splits; an explainable boosting model's shape functions; a hyperparameter search; and fairness across groups (with fairlearn installed).

    Plots that cannot be drawn are left out, with a warning, and the reason is in the table (named "auto_plot").

    AutoSampler(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Chooser

    Chooses a sampler that suits the classes and the features, or none.

    A regressed label, or classes that are already balanced (the rarest class has at least half the rows of the most common), are not resampled. Otherwise, the first of these that suits the data is applied:

    • random_under, if the rarest class has so many rows (10,000) that removing rows of the common classes still leaves plenty.
    • smote_tomek, if the classes overlap (most of the nearest neighbors of most rare rows are of other classes), since it removes pairs of rows from different classes that are each other's nearest neighbors after it adds rows.
    • smote, which adds rows between rare rows and their neighbors.
    • random_over, which duplicates rare rows. SMOTE and its variants need numeric features without missing values, mostly not binary (they make values between those of two rows, which a dummy variable cannot have), and at least 6 rows of the rarest class.

    The table (named "auto_sampler") has a row for each sampler considered (or a row for "none"), with whether it was chosen and why (or why not).

    def apply(
    self,
    item: base.Dataset,
    choices: Sequence[str] | str | None = None,
    **kwargs: Any) -> base.Dataset:
    """Resamples the training rows of `item`, if they need it.

    Args:
        item: the dataset to resample.
        choices: names of the samplers to choose from, in the order to
            prefer them. Defaults to `None`, which uses `_SAMPLERS`.
        **kwargs: parameters for the sampler (such as
            "sampling_strategy"). Each sampler uses those it accepts.

    Raises:
        ValueError: if the dataset has no label.

    Returns:
        The dataset, resampled if it needed to be.

    """
    if item.task is None:
        message = f'{self.name!r} needs a dataset with a label'
        raise ValueError(message)
    found = profile(item)
    skip = _no_sampling(found)
    if skip is not None:
        table = pd.DataFrame(
            {'chosen': [True], 'reason': [skip]},
            index = pd.Index(['none']))
        self._record(item, table, found, [])
        return item
    overlap = _overlap(item)
    names = (
        list(_SAMPLERS) if choices is None else camina.listify(choices))
    reasons = {
        name: _screen_sampler(name, found, overlap) for name in names}
    chosen = next(
        (name for name, reason in reasons.items() if reason is None),
        None)
    if chosen is None:
        message = (
            f'{self.name!r} found no sampler that suits the data: '
            + '; '.join(f'{n} {r}' for n, r in reasons.items()))
        raise ValueError(message)
    explained = {
        name: (
            _sampler_suits(name, found, overlap) if name == chosen
            else f'suits the data, but {chosen} is preferred'
            if reason is None else reason)
        for name, reason in reasons.items()}
    table = pd.DataFrame(
        {'chosen': [name == chosen for name in reasons],
         'reason': list(explained.values())},
        index = pd.Index(list(reasons)))
    _borrow(chosen)().apply(item, **kwargs)
    self._record(item, table, found, [chosen])
    return item

    def profile(item: base.Dataset) -> Profile:
    """Returns what the real training rows of `item` are like.

    Args:
        item: the dataset to profile.

    Returns:
        The profile of the training rows that a sampler did not make up.

    """
    rows = item.real_train_rows
    if len(rows) > _PROFILE_ROWS:
        generator = np.random.default_rng(item.seed)
        rows = pd.Index(generator.choice(
            rows.to_numpy(), size = _PROFILE_ROWS, replace = False))
    x = item.data.loc[rows, item.features]
    kinds = {column: base._kind_of(x[column]) for column in x.columns}
    numerics = [c for c, k in kinds.items() if k == 'numerics']
    booleans = [c for c, k in kinds.items() if k == 'booleans']
    categories = [
        c for c, k in kinds.items()
        if k == 'categoricals' and isinstance(x[c].dtype, pd.CategoricalDtype)]
    matrix = x[numerics + booleans].astype(float)
    binary = [c for c in matrix.columns if _is_binary(matrix[c])]
    continuous = matrix.drop(columns = binary)
    found = Profile(
        task = item.task,
        rows = len(rows),
        features = len(kinds),
        numerics = len(numerics),
        binaries = len(binary),
        categories = len(categories),
        text = len(kinds) - len(numerics) - len(booleans) - len(categories),
        missing = bool(x.isna().to_numpy().any()),
        unscaled = _unscaled(continuous),
        vif = _largest_vif(continuous),
        skewed = _skewed_share(continuous, len(binary)))
    if item.label is None:
        return found
    y = item.y.loc[rows]
    if item.task == 'classify':
        _profile_classes(found, y)
    elif item.task == 'regress':
        _profile_errors(found, y, matrix)
    return found

    def resolve(worker: Any) -> None:
    """Tells each "auto" technique in a workflow which genre to choose from.

    The genre of an `Auto` technique in a step is found from the name of the
    step (such as "sample", "model", or "plot"). The genre of one that is a
    technique of a worker without steps is found from the name of the worker
    (such as "artist"). An `Auto` technique that already has a genre keeps
    it.

    Args:
        worker: a workflow (a `chrisjen.Worker`).

    Raises:
        ValueError: if the genre of an "auto" technique cannot be found from
            its name.

    """
    if not isinstance(worker, chrisjen.Worker):
        return
    for node in worker:
        if isinstance(node, chrisjen.Step):
            contents = node.contents
            parts = utilities.technique_and_step(node)
            if (
                isinstance(contents, Auto)
                and contents.genre is None
                and parts is not None):
                contents.genre = _genre_of(parts[1])
            else:
                resolve(contents)
        elif isinstance(node, Auto) and node.genre is None:
            node.genre = _genre_of(str(worker.name))
        else:
            resolve(node)
