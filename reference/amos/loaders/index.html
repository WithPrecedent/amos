    amos.loaders ¶

    Techniques that load data, usually at the start of the "wrangler" stage.

    A loader makes the data of a dataset from a source: a data file, a batch of files, or a file (or OpenML dataset) that it downloads first. Loaders only download and import: whatever a file holds, they bring it into the dataset as it is, and parsers, cleaners, and mungers then work on it there. Every loader works through the project's clerk (the nagata.FileManager that is the clerk of a Project): files are looked for, and downloads are saved, in the clerk's input folder, and the clerk loads every format that it knows. A project whose workflow has a loader needs no item.

    The tools that the loaders use are public too, so they can be used outside of a project: download_file and download_linked_file download files, page_links and find_links read the links of web pages, and read_chunks reads chosen rows and columns of a huge CSV file, a chunk at a time.

    Download(contents=None, name='', parameters=dict(), clerk=None) dataclass ¶

    Bases: Loader

    Downloads a file from a URL, or a dataset from OpenML, and loads it.

    A URL's file is saved in the clerk's input folder and loaded from there, so it is only downloaded again if it is missing or "refresh" is true. Keeping the file lets others check the exact data that a project used.

    Any other source is the name (such as "credit-g") or id (such as 31) of a dataset on OpenML (https://www.openml.org), which shares thousands of datasets for research. scikit-learn saves each one in an "openml" folder in the clerk's input folder, so it is only downloaded once, and the dataset's default target is the label unless "label" is set.

    With "link", the source is instead a web page, and the file is the one that the link with those words leads to (see amos.loaders.download_linked_file), which suits sites that link to the newest release of their data from the same page.

    Wraps

    nagata.FileManager from nagata, which reads each format with pandas (such as pandas.read_csv), and sklearn.datasets.fetch_openml from scikit-learn.

    def load(
    self,
    source: Any,
    *,
    file_name: str | None = None,
    refresh: bool = False,
    timeout: float | None = None,
    link: str | None = None,
    required_member: str | None = None,
    resume: bool = False,
    session: Any = None,
    **kwargs: Any) -> Any:
    """Downloads the data at `source` (unless it was before) and loads it.

    Args:
        source: the URL of a file (http or https), of a web page that
            links to the file (with `link`), or the name or id of an
            OpenML dataset.
        file_name: name to save a URL's file as in the clerk's input
            folder, which may include folders. Defaults to `None`, in
            which case the last part of the path of the file's URL is
            used. Not used for OpenML.
        refresh: whether to download a URL's file again even if it was
            downloaded before. Defaults to `False`. Not used for OpenML.
        timeout: seconds to wait for the server of a URL to answer.
            Defaults to `None`, which uses `options._DOWNLOAD_TIMEOUT`
            (read when the file is downloaded). Not used for OpenML.
        link: the words of the link on the page at `source` that leads
            to the file, compared without regard to case or spacing
            (such as "CSV Organized by Supreme Court Citation").
            Defaults to `None`, in which case `source` is the file.
        required_member: a pattern (with "*" and "?") that the name of a
            file in the downloaded zip archive must match before it is
            saved, such as "*caseCentered*". With `link`, each link with
            its words is tried until one passes. Defaults to `None`, in
            which case the download is not checked.
        resume: whether to continue a download of a URL's file that
            stopped, instead of starting over. Defaults to `False`.
        session: an object with a `get` method like a `requests.Session`.
            Defaults to `None`, in which case one that identifies `amos`
            is made.
        **kwargs: for a URL, parameters for `read`, such as
            "file_format", "member", and parameters for the reader. For
            OpenML, parameters for `fetch_openml`, such as "version" or
            "target_column".

    Raises:
        ValueError: if `source` is a URL whose scheme is not http or
            https.

    Returns:
        The loaded data: the file's, or the OpenML dataset as
            scikit-learn returns it.

    """
    text = str(source).strip()
    scheme = urllib.parse.urlparse(text).scheme
    if not scheme:
        return self._fetch_openml(text, **kwargs)
    if scheme not in _web._SCHEMES:
        message = (
            f'only http and https URLs can be downloaded, not {text!r} '
            f'(any other source must be the name or id of an OpenML '
            f'dataset)'
        )
        raise ValueError(message)
    folder = pathlib.Path(self._get_clerk().input_folder)
    if link is not None:
        path = _web.download_linked_file(
            text,
            str(link),
            folder,
            file_name = file_name,
            refresh = refresh,
            timeout = timeout,
            session = session,
            required_member = required_member)
    else:
        path = _web.download_file(
            text,
            folder / (file_name or _web._name_of(text)),
            refresh = refresh,
            timeout = timeout,
            session = session,
            resume = resume,
            required_member = required_member)
    return self.read(path, **kwargs)

    LoadChunks(contents=None, name='', parameters=dict(), clerk=None) dataclass ¶

    Bases: Loader

    Loads chosen rows and columns of a huge CSV file, a chunk at a time.

    The file is read as read_chunks reads it (and takes its parameters): a block of bytes at a time, keeping only the columns in "columns" and the rows whose values are in "keep" (such as {"court_id": ["ca1", "ca2"]}) and that match "where" (such as "date_filed >= '2010-01-01'"), so a file of many gigabytes becomes a table of the rows that a study needs. The source is the path of the file, or its URL, in which case it is downloaded to the clerk's input folder first (and kept, so that it is only downloaded once) unless "stream" is true. Every value is read as text, and the rows are numbered from 0.

    Wraps

    pyarrow.csv.open_csv from pyarrow, and indexed_bzip2 for files compressed with bzip2.

    def load(
    self,
    source: Any,
    *,
    stream: bool = False,
    file_name: str | None = None,
    refresh: bool = False,
    resume: bool = True,
    timeout: float | None = None,
    session: Any = None,
    limit: int | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Loads the chosen rows and columns of the file at `source`.

    Args:
        source: the path of a CSV file (which may be compressed), or its
            URL (http or https). A relative path is looked for in the
            current folder and then in the clerk's input folder.
        stream: whether to read a URL's file as it arrives instead of
            downloading it first. A stream needs no disk space, but
            starts over if the connection fails, and a file compressed
            with bzip2 is then decompressed on one core. Defaults to
            `False`.
        file_name: name to save a URL's file as in the clerk's input
            folder. Defaults to `None`, in which case the last part of
            the URL's path is used.
        refresh: whether to download a URL's file again even if it was
            downloaded before. Defaults to `False`.
        resume: whether to continue a download that stopped instead of
            starting over. Defaults to `True`, since the files that need
            this loader take a long time to download.
        timeout: seconds to wait for the server of a URL to answer.
            Defaults to `None`, which uses `options._DOWNLOAD_TIMEOUT`.
        session: an object with a `get` method like a `requests.Session`.
            Defaults to `None`, in which case one that identifies `amos`
            is made.
        limit: most rows to load, such as to try out a workflow on a few.
            Reading stops once there are that many. Defaults to `None`,
            which loads every row that is kept.
        **kwargs: parameters for `read_chunks`, such as "columns",
            "keep", "where", the dialect of the file (such as
            "escape_char"), and "block_size".

    Returns:
        The rows that were kept, numbered from 0, with every value as
            text.

    """
    text = str(source).strip()
    clerk = self._get_clerk()
    folder = pathlib.Path(clerk.input_folder)
    target: pathlib.Path | str
    if urllib.parse.urlparse(text).scheme in _web._SCHEMES:
        if stream:
            target = text
        else:
            target = _web.download_file(
                text,
                folder / (file_name or _web._name_of(text)),
                refresh = refresh,
                timeout = timeout,
                session = session,
                resume = resume)
    else:
        target = _find(pathlib.Path(text).expanduser(), folder)
    frames: list[pd.DataFrame] = []
    count = 0
    chunks = read_chunks(
        target, session = session, timeout = timeout, **kwargs)
    with contextlib.closing(chunks):
        for frame in chunks:
            if limit is not None and count + len(frame) >= limit:
                frames.append(frame.iloc[:limit - count])
                break
            frames.append(frame)
            count += len(frame)
    if not frames:
        return pd.DataFrame(columns = list(kwargs.get('columns') or []))
    return pd.concat(frames, ignore_index = True)

    LoadFiles(contents=None, name='', parameters=dict(), clerk=None) dataclass ¶

    Bases: Loader

    Loads a batch of files into one table.

    The source is a folder, a pattern of paths (such as "reports/*.txt"), or a list of paths. Each file is read with the clerk, as load_file reads one, so its format comes from its name unless "file_format" names one for every file. A file of a table (such as a CSV file) adds its rows, and a file of text (a ".txt" file, or any file read with "file_format" set to "text") adds one row, with its text in the "text" column. Either way, each row has the path of its file in the "file" column, so a batch of documents becomes a table that parsers can work on all at once. The files are read at the same time, in threads, and their rows are kept in the order of their paths.

    Wraps

    nagata.FileManager from nagata, which reads each format with pandas (such as pandas.read_csv).

    def load(
    self,
    source: Any,
    *,
    pattern: str = '*',
    recursive: bool = True,
    file_column: str = 'file',
    text_column: str = 'text',
    limit: int | None = None,
    workers: int | None = None,
    **kwargs: Any) -> pd.DataFrame:
    """Loads the files at `source` into one table.

    Args:
        source: a folder, a pattern of paths (such as "reports/*.txt"),
            or a list of paths of files. A relative path or pattern is
            looked for in the current folder and then in the clerk's
            input folder.
        pattern: the pattern of the names of the files to load from a
            folder (such as "*.txt"). Defaults to "*", which loads every
            file. Not used for other sources.
        recursive: whether to load the files of a folder's subfolders
            too. Defaults to `True`. Files and folders whose names start
            with "." are left out.
        file_column: name of the column with the path of each row's file:
            relative to the folder (or to the folder in which a pattern
            was found), or else as given, with "/" between its parts.
            Defaults to "file".
        text_column: name of the column with the text of each file of
            text. Defaults to "text".
        limit: most files to load (the first, in the order of their
            paths), such as to try out parsers on a few. Defaults to
            `None`, which loads every file.
        workers: most threads that read files at once. Defaults to `None`,
            which lets Python choose (from the number of processors).
        **kwargs: parameters for `read`, such as "file_format" and
            parameters for the reader (such as "sep").

    Raises:
        FileNotFoundError: if there are no files to load.
        TypeError: if a file holds neither a table nor text.
        ValueError: if some files are tables and others are text.

    Returns:
        The rows of every file, numbered from 0, with `file_column`
            first.

    """
    clerk = self._get_clerk()
    found = _find_files(
        source,
        pathlib.Path(clerk.input_folder),
        pattern = pattern,
        recursive = recursive)
    if limit is not None:
        found = found[:limit]
    if not found:
        message = f'there are no files to load at {source!r}'
        raise FileNotFoundError(message)
    paths = [path for path, _ in found]
    with concurrent.futures.ThreadPoolExecutor(
        max_workers = workers) as pool:
        loaded = list(pool.map(
            functools.partial(self.read, **kwargs), paths))
    return _combine(
        [name for _, name in found],
        loaded,
        file_column = file_column,
        text_column = text_column)

    Loader(contents=None, name='', parameters=dict(), clerk=None) dataclass ¶

    Bases: Operation, ABC

    Base class for techniques that load data.

    A subclass writes a load method, which takes a source (such as a path or a URL) and returns the data. Most loaders get a file and pass it to read, which loads it with the clerk. The source is the "source" parameter, usually set in the "{name}_parameters" section of the settings.

    A loader starts the dataset that the rest of the workflow works on. The new dataset keeps the seed and history of the dataset that the loader is applied to, and its label and groups unless the loader's parameters set them. Everything else, including the task (unless "task" is set), comes from the loaded data. A loader built from a project's settings uses the project's clerk, and the "label", "task", and "groups" of the "general" section are its default parameters.

    A file that holds a whole Dataset (such as one that save_data saved) goes on from where it was saved: it keeps its own label, task, seed, groups, split, and everything it learned, and its history follows the history of the dataset that the loader is applied to.

    def download_file(
    url: str,
    path: pathlib.Path | str,
    *,
    refresh: bool = False,
    timeout: float | None = None,
    session: Any = None,
    resume: bool = False,
    required_member: str | None = None) -> pathlib.Path:
    """Downloads a file, unless it was downloaded before.

    The file is written beside `path` (with ".part" added to its name) as it
    arrives, and is renamed to `path` once it is whole, so a download that
    stops is never mistaken for the data. Large files (even of many
    gigabytes) are written a piece at a time, so they need little memory.

    Args:
        url: the address of the file (http or https).
        path: where to save it. Its folder is made if needed, and "~" is the
            user's home folder.
        refresh: whether to download the file even if there is one at
            `path`. Defaults to `False`.
        timeout: seconds to wait for the server to answer. Defaults to
            `None`, which uses `options._DOWNLOAD_TIMEOUT` (read when the
            file is downloaded).
        session: an object with a `get` method like a `requests.Session`.
            Defaults to `None`, in which case `open_session` makes one.
        resume: whether to continue a download that stopped (whose ".part"
            file is still there) instead of starting over, if the server
            sends parts of files. A download that fails keeps its ".part"
            file. Defaults to `False`, in which case a download that fails
            leaves no file behind.
        required_member: a pattern (with "*" and "?", as in `fnmatch`) that
            the name of a file in the downloaded zip archive must match
            before the archive is saved, such as "*caseCentered*.csv" to be
            sure that a link led to the right file. Defaults to `None`, in
            which case the download is not checked.

    Raises:
        OSError: if the download stopped before the whole file arrived.
        ValueError: if the scheme of `url` is not http or https, or the
            download is not a zip archive with a file that matches
            `required_member`.
        requests.HTTPError: if the server refuses the request (or whatever
            the `raise_for_status` method of `session`'s responses raises).

    Returns:
        The path of the file.

    """
    path = pathlib.Path(path).expanduser()
    if path.is_file() and not refresh:
        return path
    _check_scheme(url)
    path.parent.mkdir(parents = True, exist_ok = True)
    partial = path.with_name(f'{path.name}{_PARTIAL}')
    start = partial.stat().st_size if resume and partial.is_file() else 0
    headers = {'Range': f'bytes={start}-'} if start else {}
    seconds = options._DOWNLOAD_TIMEOUT if timeout is None else timeout
    response = open_session(session).get(
        url, headers = headers, stream = True, timeout = seconds)
    try:
        response.raise_for_status()
        # A server that does not send parts of files sends the whole file.
        partly = bool(start) and getattr(
            response, 'status_code', http.HTTPStatus.OK) == (
            http.HTTPStatus.PARTIAL_CONTENT)
        expected = _length(response)
        written = _write(response, partial, append = partly)
        _check_length(written, expected, url, resume = resume)
        if required_member is not None:
            _check_member(partial, required_member, url)
        partial.replace(path)
    except BaseException:
        if not resume:
            partial.unlink(missing_ok = True)
        raise
    finally:
        _close(response)
    logger.info('downloaded %s to %s', path.name, path.parent)
    return path

            the link's address is used.

            no `file_name`, the page is always read, to name the file.
            Defaults to `False`.
        timeout: seconds to wait for the server to answer. Defaults to

            Defaults to `None`.

        ValueError: if no link with those words leads to a zip archive with
            a file that matches `required_member`.

    Returns:
        The path of the file.

    folder = pathlib.Path(folder).expanduser()
    if file_name and (folder / file_name).is_file() and not refresh:
        return folder / file_name
    session = open_session(session)
    addresses = find_links(url, link, session = session, timeout = timeout)
    if not addresses:
        message = f'there is no link to {link!r} on {url}'
        raise LookupError(message)

        download_file,
        refresh = refresh,
        timeout = timeout,
        session = session,
        required_member = required_member)
    # Each address but the last is tried in turn, and the last one's error
    # (if every one fails) is the one raised.
    for address in addresses[:-1]:
        try:
            return fetch(address, folder / (file_name or _name_of(address)))
        except ValueError as error:
            logger.info('skipped %s: %s', address, error)
    last = addresses[-1]
    return fetch(last, folder / (file_name or _name_of(last)))

    source: pathlib.Path | str,
    *,
    columns: Sequence[str] | None = None,
    keep: Mapping[str, Any] | None = None,
    where: str | Callable[[pd.DataFrame], Any] | None = None,
    delimiter: str = ',',
    quote_char: str | None = '"',
    double_quote: bool = True,
    escape_char: str | None = None,
    newlines_in_values: bool = True,
    encoding: str = 'utf-8',
    empty_as_missing: bool = False,
    block_size: int | None = None,
    processes: int | None = None,
    session: Any = None,
    timeout: float | None = None,
    report_every: int | None = None) -> Generator[pd.DataFrame, None, None]:
    r"""Yields chosen rows and columns of a huge CSV file, a chunk at a time.

    The file is read a block of bytes at a time ("block_size"), and each
    block is parsed on every core by pyarrow. The rows whose values are in
    `keep` are found in each block before any of its text becomes Python
    objects, so a file of many gigabytes takes about as long to read as to
    decompress. A file compressed with bzip2 (".bz2") is decompressed on
    every core with indexed_bzip2; one compressed with gzip, xz, or
    Zstandard (".gz", ".xz", or ".zst") is decompressed as it is read. A URL
    is read as it arrives, without saving it (see `download_file` to save it
    first).

    Every value is read as text, so that ids and dates keep their exact
    form. Convert columns afterward (such as with `convert_types` or
    `clean_numbers`).

    Args:
        source: the path of a CSV file (which may be compressed) or its URL
            (http or https). Its first line names its columns. "~" is the
            user's home folder.
        columns: the columns to return, in that order. Those that the file
            does not have are left out (with a warning in the log), since
            the columns of a published file can change from one release to
            the next. Defaults to `None`, which returns every column.
        keep: the values to keep of each of some columns, such as
            `{"court_id": ["ca1", "ca2"]}`: a row is kept only if each of
            these columns has one of its values. Values are compared as text
            (so 5 matches "5"), and one value need not be in a list. The
            columns need not be in `columns`. Defaults to `None`, which keeps
            every row.
        where: which of the rows (after `keep`) to keep: an expression for
            `pandas.DataFrame.query`, such as `"date_filed >= '2010-01-01'"`,
            or a function that takes a chunk and returns a boolean value
            for each of its rows. It sees the columns in `columns`. Defaults
            to `None`, which keeps every row.
        delimiter: the character between values. Defaults to ",".
        quote_char: the character that quotes a value, or `None` if values
            are not quoted. Defaults to '"'.
        double_quote: whether two quote characters in a quoted value stand
            for one. Defaults to `True`.
        escape_char: the character that makes the next one stand for itself
            (such as "\\", which PostgreSQL writes before quotes in values),
            or `None` for none. Defaults to `None`.
        newlines_in_values: whether quoted values can hold line breaks.
            Defaults to `True`.
        encoding: the encoding of the file. Defaults to "utf-8".
        empty_as_missing: whether empty values are missing rather than empty
            text. Defaults to `False`.
        block_size: how many bytes are parsed at a time, which must be more
            than the longest row (a few rows of court records hold megabytes
            of text). Defaults to `None`, which uses `options._BLOCK_SIZE`.
        processes: how many cores decompress a file compressed with bzip2.
            Defaults to `None`, which uses every core.
        session: an object with a `get` method like a `requests.Session`,
            for a URL. Defaults to `None`, in which case one that identifies
            `amos` is made.
        timeout: seconds to wait for the server of a URL to answer. Defaults
            to `None`, which uses `options._DOWNLOAD_TIMEOUT`.
        report_every: how many rows are read between the reports of progress
            in the log (at the "info" level). Defaults to `None`, which uses
            `options._REPORT_EVERY`.

    Raises:
        KeyError: if a column of `keep` is not in the file.
        ValueError: if a row is longer than `block_size`, or the file has no
            line of column names.

    Yields:
        pd.DataFrame: the rows of each block that are kept (blocks without
            any are skipped), with every value as text. Each row's label is
            its place in the file (0 for the first row after the column
            names).

    """
    name = _name_of(source)
    every = options._REPORT_EVERY if report_every is None else report_every
    wanted = _values_to_keep(keep)
    with _open(
        source,
        processes = processes,
        session = session,
        timeout = timeout) as raw:
        header = _header(
            raw,
            delimiter = delimiter,
            quote_char = quote_char,
            double_quote = double_quote,
            escape_char = escape_char,
            encoding = encoding)
        missing = [column for column in wanted if column not in header]
        if missing:
            message = f'{name} has no column {missing}: it has {header}'
            raise KeyError(message)
        output = _columns_in(header, columns, name)
        read = list(dict.fromkeys([*output, *wanted]))
        reader = arrow_csv.open_csv(
            raw,
            read_options = arrow_csv.ReadOptions(
                column_names = header,
                block_size = block_size or options._BLOCK_SIZE,
                use_threads = True,
                encoding = encoding),
            parse_options = arrow_csv.ParseOptions(
                delimiter = delimiter,
                quote_char = quote_char or False,
                double_quote = double_quote,
                escape_char = escape_char or False,
                newlines_in_values = newlines_in_values),
            convert_options = arrow_csv.ConvertOptions(
                include_columns = read,
                column_types = dict.fromkeys(read, pa.large_string()),
                strings_can_be_null = empty_as_missing,
                quoted_strings_can_be_null = empty_as_missing))
        count = 0
        for batch in _batches(reader, name):
            start, count = count, count + batch.num_rows
            if every and start // every != count // every:
                logger.info('%s: %d rows read', name, count)
            frame = _chosen(batch, wanted, output, start)
            if where is not None and len(frame):
                frame = _where(frame, where)
            if len(frame):
                yield frame
        logger.info('%s: read all %d rows', name, count)
