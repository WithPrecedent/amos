    AmosWarning ¶

    Bases: UserWarning

    A warning from amos about something that a user may want to change.

    amos warns when it does something other than what was asked, so that the results can still be made (such as fitting a model on the CPU when it could not use the GPU, or leaving out a technique that a chooser could not apply). Its warnings are this category, so they can be filtered apart from those of the packages that amos uses:

    import warnings
warnings.simplefilter("error", amos.AmosWarning)

    AssumptionError ¶

    Bases: ValueError

    Raised when the data does not meet an assumption or need of a technique.

    It is raised before the technique is applied (by a pretest) or after its model is fitted (by an audit) if the dataset's assumption_violations is "raise", and for a need that the technique cannot be applied without (such as a model that cannot use missing values), whatever the setting, outside of an experiment. It is not an IncompatibleTechniqueError, so a workflow does not skip it.

    Branch(label, steps, result, score=None, criterion=None, source=None) dataclass ¶

    One branch of an experiment: a combination of techniques and its result.

    An experiment tries every combination of one technique from each step. Each combination is a branch. The winning dataset keeps a Branch for every one of them, so that a scorecard can compare them after the experiment.

    A branch also refers to the whole dataset that it made (with its fitted model and features), which the experiment keeps in its results, so that a regression_table can estimate the effects of each branch's model. The reference is weak: it does not keep the dataset in memory, and copies and pickles of the branch do not have it. An experiment that conserves memory keeps only the winner's dataset, so the other branches have none.

    Data and everything learned from it in a workflow.

    A Dataset is the item that an amos workflow works on. It holds the data in a single pandas.DataFrame, the name of the column that models predict (the label), and the rows in the training and test sets. As a workflow runs, each technique adds what it learns: the fitted model, its predictions, metrics, tables, figures, and a record of every step in history.

    The data stays in one DataFrame even after it is split. Transformers learn from the training rows and then change every row, so nothing is learned from the test rows, and every row keeps its original label in the index.

def create(
    cls,
    item: Any,
    *,
    label: str | None = None,
    task: str | None = None,
    seed: int | None = None,
    groups: Sequence[str] | str | None = None,
    use_gpu: bool | None = None,
    visualize_explorers: bool | None = None,
    visualize_critics: bool | None = None,
    order: str | None = None,
    assumption_violations: str | None = None) -> Dataset:
    """Returns a `Dataset` made from `item`.

    Args:
        item: a `Dataset`, a `pandas.DataFrame` or `Series`, a Polars
            `DataFrame` or `LazyFrame`, a `numpy` array, a `dict` of
            columns, the path to a data file in any format that `nagata`
            knows (see `loaders.LoadFile`), or an object with a `frame`
            attribute (such as a scikit-learn dataset loaded with
            `as_frame = True`). A file that holds a whole `Dataset`
            (such as one that `save_data` saved) is loaded as that
            `Dataset`.
        label: name of the label column. Defaults to `None`. If `item` has
            a `target` (as a scikit-learn dataset does), its name is used.
        task: "classify" or "regress". Defaults to `None`, in which case
            it is inferred from the label.
        seed: seed for every random process. Defaults to `None`.
        groups: names of the columns that identify groups of rows.
            Defaults to `None`.
        use_gpu: whether models that can be fitted on a GPU use one.
            Defaults to `None`, which is `False` for a new `Dataset`.
        visualize_explorers: whether every explorer draws a figure of
            its table. Defaults to `None`, which leaves it to each
            explorer's `visualize` argument.
        visualize_critics: whether every critic draws a figure of its
            table. Defaults to `None`, which leaves it to each critic's
            `visualize` argument.
        order: name of the column that puts the rows in order. Defaults
            to `None`.
        assumption_violations: what amos does when the data does not
            meet an assumption of a technique ("raise", "warn",
            "ignore", or "skip"). Defaults to `None`, which is "warn"
            for a new `Dataset`.

    Raises:
        FileNotFoundError: if `item` is a path and there is no file there.
        TypeError: if `item` cannot be made into a `Dataset`.
        ValueError: if `item` is a path to a file whose format is not
            known.

    Returns:
        A `Dataset`. If `item` is already a `Dataset`, it is returned
            with any of `label`, `task`, `seed`, `groups`, and `order`
            that it lacks, and with `use_gpu`, `visualize_explorers`,
            `visualize_critics`, and `assumption_violations` if they are
            passed.

    """
    if isinstance(item, Dataset):
        if item.label is None and label is not None:
            item.label = label
            item.task = task or (
                item.infer_task() if item.has_label else None)
        if item.task is None and task is not None:
            item.task = task
        if item.seed is None:
            item.seed = seed
        if not item.groups and groups:
            item.groups = _validate_groups(groups, item.data, item.label)
        if use_gpu is not None:
            item.use_gpu = _validate_use_gpu(use_gpu)
        if visualize_explorers is not None:
            item.visualize_explorers = _validate_switch(
                visualize_explorers, 'visualize_explorers')
        if visualize_critics is not None:
            item.visualize_critics = _validate_switch(
                visualize_critics, 'visualize_critics')
        if item.order is None and order is not None:
            item.order = _validate_order(order, item.label, item.groups)
        if assumption_violations is not None:
            item.assumption_violations = _validate_policy(
                assumption_violations)
        return item
    if isinstance(item, str | pathlib.Path):
        # `loaders` imports this module, so it is imported here. The file
        # is read as `load_file` reads it, with a clerk for the current
        # folder.
        from ..wrangler import loaders  # noqa: PLC0415
        item = loaders.LoadFile().read(item)
        if isinstance(item, Dataset):
            # A file that a saver (such as `save_data`) saved holds a
            # whole dataset, which goes on from where it was saved.
            return cls.create(
                item,
                label = label,
                task = task,
                seed = seed,
                groups = groups,
                use_gpu = use_gpu,
                visualize_explorers = visualize_explorers,
                visualize_critics = visualize_critics,
                order = order,
                assumption_violations = assumption_violations)
    if type(item).__module__.startswith('polars'):
        # Polars is optional, so its frames are recognized by their module.
        # A `LazyFrame` is collected first.
        frame = item.collect() if hasattr(item, 'collect') else item
        data = frame.to_pandas()
    elif isinstance(item, pd.DataFrame):
        data = item
    elif isinstance(item, pd.Series):
        data = item.to_frame()
    # A scikit-learn dataset is a `dict`, so it is checked before other
    # mappings.
    elif isinstance(getattr(item, 'frame', None), pd.DataFrame):
        data = item.frame
        target = getattr(item, 'target', None)
        if label is None and isinstance(target, pd.Series):
            label = str(target.name)
    elif isinstance(item, np.ndarray | Mapping):
        data = pd.DataFrame(item)
    else:
        message = f'a Dataset cannot be made from {type(item).__name__}'
        raise TypeError(message)
    return cls(
        data = data,
        label = label,
        task = task,
        seed = seed,
        groups = camina.listify(groups),
        use_gpu = _validate_use_gpu(use_gpu),
        visualize_explorers = visualize_explorers,
        visualize_critics = visualize_critics,
        order = order,
        assumption_violations = assumption_violations or 'warn')

    def infer_task(self) -> str:
    """Returns the task implied by the type of the label.

    A label that is boolean, categorical, or text is classified. So is an
    integer label with `options._CLASSIFY_THRESHOLD` unique values or
    fewer (such as 0 and 1), or a label of whole numbers stored as floats
    with only two unique values. Any other label is regressed. Pass `task`
    to override this.

    Returns:
        "classify" or "regress".

    """
    label = self.y
    unique = label.nunique(dropna = True)
    if not pd.api.types.is_numeric_dtype(label.dtype):
        return 'classify'
    if pd.api.types.is_bool_dtype(label.dtype):
        return 'classify'
    if pd.api.types.is_integer_dtype(label.dtype):
        if unique <= options._CLASSIFY_THRESHOLD:
            return 'classify'
        return 'regress'
    values = label.dropna()
    if unique <= 2 and bool((values == values.round()).all()):  # noqa: PLR2004
        return 'classify'
    return 'regress'

    self,
    x: pd.DataFrame,
    y: Sequence[Any],
    origins: Sequence[int] | np.ndarray | None = None) -> None:
    """Replaces the training rows with `x` and `y`.

    Samplers add or remove training rows. The test rows (and their index
    labels) are not changed. The new training rows are given new index
    labels: integers after the largest current label if the index is made
    of integers, and otherwise "resampled_0", "resampled_1", and so on.
    The first copy of each real row is real. Synthetic rows and any other
    copies are added to `synthetic`.

    Args:
        x: features of the new training rows.
        y: labels of the new training rows.
        origins: for each new row, the position (in the training rows) of
            the row it copies, which gives it that row's groups (and
            order), or -1 for a synthetic row, which has none. Defaults
            to `None`, in which case no new row has groups and every new
            row is real.

    """
    label = self.require_label()
    made_up = self.train_rows.isin(self.synthetic)
    rows = x.copy()
    rows[label] = np.asarray(y)
    kept = [*self.groups, *self._order_column()]
    if kept:
        training = self.data.loc[self.train_rows, kept]
        positions = np.full(len(rows), -1) if origins is None else (
            np.asarray(origins))
        copied = positions >= 0
        for column in kept:
            values = pd.Series(
                pd.NA, index = rows.index, dtype = training[column].dtype)
            values[copied] = training[column].to_numpy()[
                positions[copied]]
            rows[column] = values
    rows.index = self._new_labels(len(rows))
    rows = rows[self.data.columns]
    test = self.data.loc[self.test_rows] if self.is_split else None
    self.data = pd.concat([rows, test]) if test is not None else rows
    self.train = rows.index
    self.synthetic = rows.index[_made_up(origins, made_up, len(rows))]

    def update_features(
    self,
    columns: Sequence[str],
    values: pd.DataFrame) -> None:
    """Replaces the feature `columns` with `values`.

    Transformers use this to swap the columns they were given for the
    columns they produce, which may have different names or a different
    number of columns (one-hot encoding, for example). The new columns
    take the place of the first column they replace, so the order of the
    other columns does not change.

    Args:
        columns: names of the columns to remove.
        values: the new columns, with the same index as `data`.

    Raises:
        ValueError: if `values` has a different index from `data`, or if a
            new column has the same name as a column that is kept.

    """
    if not values.index.equals(self.data.index):
        message = 'the new columns must have the same index as the data'
        raise ValueError(message)
    removed = set(columns)
    kept = [c for c in self.data.columns if c not in removed]
    clashes = [c for c in values.columns if c in kept]
    if clashes:
        message = (
            f'the new columns {clashes} have the same names as columns '
            f'that are kept'
        )
        raise ValueError(message)
    place = min(
        (i for i, c in enumerate(self.data.columns) if c in removed),
        default = len(self.data.columns))
    before = [c for c in self.data.columns[:place] if c not in removed]
    after = [c for c in self.data.columns[place:] if c not in removed]
    self.data = pd.concat(
        [self.data[before], values, self.data[after]], axis = 1)

    IncompatibleTechniqueError ¶

    Bases: ValueError

    Raised by a technique that does not suit the dataset's model.

    In a workflow, the technique is skipped and the skip is recorded in the dataset's history (see skipping_incompatible_techniques), so one that an experiment applies after every path does not end the run when a path's model cannot use it. Otherwise, as when apply is called directly, the error is raised. An error in how a technique was used (such as a parameter that is wrong, or a model that has not been applied yet) should not be this error.

    Operation(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Technique, ABC

    Base class for every amos technique: one step that changes a Dataset.

    A technique takes a dataset, does one thing to it (loads data, cleans a column, fits a model, draws a figure, and so on), and returns it. The dataset is changed in place, and the technique adds an entry to its history. Calling a technique on something that is not yet a Dataset (such as a pandas.DataFrame) makes it into one first.

    Every subclass is registered in the chrisjen.library under its name in snake case (CleanBooleans is "clean_booleans"), which is the name that settings use for it.

    A technique that does not suit the dataset's model raises an IncompatibleTechniqueError before it changes anything. In a workflow, the technique is then skipped rather than ending the run: a warning is logged, and its entry in history has "skipped" (True) and the "reason" (see skipping_incompatible_techniques). A direct call to apply raises the error.

    Techniques are grouped into kinds, called genres, each with an abstract base class: Loader, Parser, Cleaner, Munger, Merger, Shaper, Saver, Describer, Splitter, Transformer, Sampler, Model, Validator, Evaluator, Inferer, and Plot. To add a technique, subclass the genre that fits and write the method it requires, or set contents to the tool to wrap. To add a new genre, subclass Operation and write apply. (Metrics are not techniques: see amos.metrics.Metric.)

    In a project, a plot, evaluator, or inferer can be replaced by the techniques that the dataset's model names in its parameters (see using_model_specific_techniques).

    A technique can list, by name, the assumptions it makes about the data and the needs it has of it (see the conditions module), as every model does. Before it is applied, the pretests of each are run on the data, and the dataset's assumption_violations decides what is done if the data does not meet one (see _check_conditions).

    SkippedBranchError ¶

    Bases: AssumptionError

    Raised to leave a branch out of an experiment.

    In a branch of an Experiment, a technique raises it before it is applied if the data does not meet one of its assumptions and the dataset's assumption_violations is "skip", or if the data does not meet a need that the technique cannot be applied without. The experiment leaves the branch out of its comparison and records why.

    Visualizer ¶

    Mixin for explorers and critics, which can draw a figure of a table.

    The apply of an explorer (a describer) or a critic (an evaluator or an inferer) takes visualize, which is False unless it is passed (or set in the technique's parameters). If it is True, the technique draws the figure that suits its table with the plot named by visual, in the style of every plot (see plots.Plot.make_figure), and stores it in the dataset's figures under the technique's name. Its entry in history then has "figure".

    The dataset's visualize_explorers or visualize_critics (which a project sets from the settings of the same names in the "general" section) replaces the argument of every technique of its stage, if it is set: True draws every figure, and False draws none, whatever the argument says. Neither is set unless the settings or the dataset set it.

    A figure that cannot be drawn (because matplotlib is not installed, or the plot does not suit the table) does not end the technique: a warning is logged, the table is kept, and the technique's entry in history has the reason as "figure_error".
