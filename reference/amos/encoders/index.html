    amos.encoders ¶

    Techniques that turn categories, text, and dates into numbers.

    These are preprocessing techniques of the "analyst" stage. Each one wraps an encoder from scikit-learn, category_encoders, or skrub, which is fitted to the training rows only (and is given the label, which target encoders need) and then encodes every row, so nothing is learned from the test rows. By default, an encoder changes the categorical and text features (dates, for date_parts). Pass columns as a parameter to choose others.

    WeightOfEvidence

    Replaces each category with its weight of evidence (binary labels).

    Encoder(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Transformer, ABC

    Base class for techniques that turn categories and text into numbers.

    Supervised encoders (such as target) are fitted with the training labels. A label of text is given to them as the position of each class in Dataset.classes.

    Gap(contents='skrub.GapEncoder', name='', parameters=dict()) dataclass ¶

    Bases: Encoder

    Encodes messy text as a mix of topics of its substrings.

    Useful for text with typos or variations (such as "St. Louis" and "Saint Louis"). Each new column is named for the most common substrings of its topic, so it can be interpreted. It wraps skrub's GapEncoder (10 topics by default).
