    amos.audits ¶

    Techniques that check the assumptions of a fitted model from its errors.

    These are techniques of the "critic" stage. Some assumptions of a model can only be checked after it is fitted: whether its errors are normal (audit_residuals), have constant variance (audit_errors), and are independent (audit_independence). Each audit adds a table of what it found to the dataset's tables under its name, and audit_assumptions runs the audits of every assumption that the dataset's model makes:

    [general]
label = target
order = date

[critic]
techniques = audit_assumptions, scorecard

    The "assumption_violations" setting of the "general" section decides what amos does when the data does not meet an assumption that the model makes: "raise" an error, "warn" (the default), or "ignore" it. With "skip", an audit in a branch of an experiment leaves the branch out, but a critic after an experiment (which sees only the winning branch) warns.

    Base class for techniques that check a fitted model's assumptions.

    Some assumptions (such as errors of constant variance) can only be checked from the errors of a fitted model. An audit checks the assumptions that it is named for (each condition's audited_by) from the errors of the dataset's model on the rows that it predicted (the test rows, or every row if the data is not split). It adds a table to the dataset's tables under its name, with a row for each assumption: whether the data meets it, the statistic of its test, and what was found. The rows are also added to the "assumptions" table, with those of the pretests.

    An assumption that the model makes (one in its assumptions) and that the data does not meet is a violation, which the dataset's assumption_violations decides what to do about: "raise" an AssumptionError, "warn" (the default), or "ignore" it. With "skip", a branch of an experiment that audits its own model is left out, but a critic after an experiment (which sees only the winning branch) warns. An audit also tests an assumption that the model does not make, but that is never a violation.

    def apply(self, item: base.Dataset, **kwargs: Any) -> base.Dataset:
    """Checks the assumptions of the dataset's model from its errors.

    Args:
        item: the dataset, with a fitted model and its predictions.
        **kwargs: not used.

    Raises:
        AssumptionError: if the model makes an assumption that the data
            does not meet, and the dataset's `assumption_violations` is
            "raise".
        SkippedBranchError: if it does so in a branch of an experiment,
            and `assumption_violations` is "skip".
        ValueError: if there is no fitted model with predictions.

    Returns:
        The dataset, with the table of verdicts.

    """
    if item.model is None or item.predictions is None:
        message = (
            f'{self.name!r} needs a fitted model and its predictions: '
            f'apply a model first')
        raise ValueError(message)
    technique = _model_technique(item)
    verdicts = conditions.judge_after(
        item, technique, check = self._check())
    item.tables[self.name] = conditions.tabulate(verdicts)
    conditions.record(
        item, verdicts, technique = self.name, role = 'audits')
    conditions.enforce(item, verdicts)
    return item

    Bases: Audit

    Checks every assumption of the model that has an audit.

    It runs every other audit, but only for the assumptions that the dataset's model makes, so a model that makes none (such as a random forest) has an empty table. Name it in the "critic" stage:

    [critic]
techniques = audit_assumptions, scorecard

    AuditErrors(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Audit

    Checks whether the model's errors have constant variance.

    It checks "constant_variance" with Breusch and Pagan's test, which regresses the squared errors on the numeric features (see assumptions.ConstantVariance).

    AuditIndependence(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Audit

    Checks whether the model's errors are independent.

    It checks "independent_errors": with Breusch and Godfrey's test (and Durbin and Watson's statistic) of the errors in the dataset's order, and with the intraclass correlation of the errors within its first group column (see assumptions.IndependentErrors). A dataset with neither an order nor groups cannot be tested.

    AuditProportionalHazards(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Audit

    Checks whether each feature's effect on a Cox model's hazard is constant.

    It checks "proportional_hazards" of a fitted cox model with Grambsch and Therneau's test of the correlation of each feature's Schoenfeld residuals with the rank of the time (see assumptions.ProportionalHazards).

    AuditResiduals(contents=None, name='', parameters=dict()) dataclass ¶

    Bases: Audit

    Checks whether the model's errors are normal.

    It checks "normal_errors" with D'Agostino and Pearson's test and the skewness and excess kurtosis of the errors, and reports the share that are outliers (see assumptions.NormalErrors).
